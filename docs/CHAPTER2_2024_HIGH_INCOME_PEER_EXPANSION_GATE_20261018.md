# 第2章｜2024年「同世代×同所得帯」未対応区分の拡張ゲート（2026-10-18）

## 現在地（確定情報）
- 元表：総務省「令和6年全国家計構造調査」表1-29-1 / e-Stat統計表ID `0004039867`。
  https://www.e-stat.go.jp/dbview?sid=0004039867
- 表は「世帯の種類 × 世帯区分 × 世帯主の年齢階級 × 年間収入階級 × 収支項目」の実交差表。
- 表には年間収入の50万円刻み区分のほか、**（再掲）1000～1250万円／1250～1500万円／1500万円以上**がある（e-Statメタデータに存在）。
- 現行画面の `1000plus` は1,000万円以上の開区間。これを任意の高額所得階級へ自動変換してはならない。
- 2024年の単身・二人以上勤労者の検証済みセルは合計79行（原表で確認済みの範囲）。現行のデータセットに1,000万円以上の検証済み行はない。
- 現行の1セルの概数標本数のプロダクト表示閾値は50世帯以上。これは統計学的な有意性保証ではない。

## 次の採録優先順位
1. 二人以上×勤労者世帯、世帯主30–39、40–49、50–59歳について、`（再掲）1000～1250万円`、`（再掲）1250～1500万円`、`（再掲）1500万円以上`の概数標本数・可処分所得・食料・光熱水道・家事雑貨・家事用消耗品を**同じ原表セル**から確認。
2. 続いて単身×勤労者世帯の同年齢・同額面年収区分を確認。小標本や欠損は非表示とする。
3. データ照合記録に、日本語の元区分ラベル、原表値、取得日時、元ファイルのハッシュ、独立照合者、欠損・秘匿フラグを保存。二重確認前に`verifiedOfficialCell=true`としない。
4. これらが揃って初めて、**表示専用の任意年収細分化**（1000～1249 / 1250～1499 / 1500万円以上）を第2章に追加する。本体のFROZENプロフィールや判定エンジンの`1000plus`は変更しない。
5. 上記を満たせない区分は従来の2025年「所得帯だけ」の参考値（年齢未照合）に戻し、同年代の平均とは呼ばない。

## 絶対に越えない境界
- 同一交差セルの食費等平均÷可処分所得平均＝**比率の平均ではなく平均値の比**。賞与・調査定義は利用者の月手取りと同一ではない。
- 年齢は**世帯主の年齢**。多人数で入力者と世帯主が異なる場合、同年齢比較は不可。
- 勤労者世帯は世帯主が雇用され給与等を受け取る世帯。2026-10-18の改修で利用者の自己申告を確認する表示ゲートを追加した。自己申告は公的統計上の本人照合ではない。
- 食費／光熱水道／日用品以外へ推定比率を拡張しない。日用品＝「家事雑貨＋家事用消耗品」の独自定義を表示する。
- 原表の50万円区分と再掲集合を重複カウント・合計・仮想加重しない。
- 比較差、負担率、上限超過は**CONFIRMED saving、月額改善バッファ、cUpper、シナリオ金額へ加算しない**。

## リリース条件
- 対象人口・表章項目・年代・所得帯の区分完全一致、n≥50、抑制値なし。
- 同一セルの月次可処分所得と費目支出を照合、本人の額面年収選択を任意とする。
- 単身／二人以上×勤労者確認、本人年齢・世帯主年齢の区別、対象外のfail-closed QA。
- 画面文言は「参考幅＝別々に公表された区分平均の最小～最大」とし、個々の世帯の分布ではないと明示。
