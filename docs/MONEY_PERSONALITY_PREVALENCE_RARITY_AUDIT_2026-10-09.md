# 第1章32TYPE希少性監査（人口モデル感度）V1
更新日：2026-10-09

## この監査で分かったこと
**「現行8 JOBが均等に出る」とは限らない。ほぼ均等だった理由は、シミュレーターの仮想人口が対称・独立に作られていることだった。** 同じ判定エンジンへ異なる入力人口を入れるだけで、珍しい組み合わせが発生する。

現実の日本人・SNS利用者・顧客データを使用していない。『このタイプは日本人の0.68%』等の人口頻度主張には一切使えない。

## 実行方法と検証証拠
- `qa-money-personality-prevalence-sensitivity-v1.ts`
- 現行の`evaluateMoneyPersonality`に対して30 CORE＋必要なAdaptive/Separatorを全件通過。
- **固定乱数シード、4仮想モデル×10,000人＝40,000件**。設問回答ノイズ：5段階で標準偏差0.77。
- GitHub Actions Run [#37865981632](https://github.com/mudagiri/mudagii/actions/runs/37865981632) でPASS。

- 判定エンジン・閾値・設問・称号・第2章 V1 FROZENには一切変更なし。

## モデルの違い
1. **対称・独立**：F/D/Mの優勢方向をそれぞれ確率0.5で独立に生成。4 STYLEが優勢になる機会を各0.25にする。
2. **周辺確率のみ偏り**：F 0.68、D 0.62、M 0.72。4STYLEの優勢候補 0.38/0.30/0.21/0.11。これらは実測値ではない。
3. **軸間相関あり**：F 0.62。D と M は F が強いかどうかで条件付き確率を変更。STYLEの優勢候補もFによって変える。あくまで相関があった場合の感度確認。
4. **仮のSNS流入像**：F 0.28、D 0.33、M 0.34。4STYLEの優勢候補 0.20/0.58/0.08/0.14。実際のSNSユーザーの調査ではない。

### どんな結論を導けるか
- 1つ目のモデルがほぼ均等なのは **分類器が均等配分を強制しているからではない**。生成の入口が対称であり、分類器自体は入力に偏りを反映できる。
- 8 JOBの出現頻度には、各軸の片側が強い割合と3軸同士の相関が効く。32TYPEにはさらにSTYLEの優勢割合が効く。
- ゆえに「希少なJOBがゼロ」「希少な32TYPEがゼロ」という推論も、「希少タイプは確実にある」という推論も、現時点で実測されていない。
- MBTIの出現頻度を模して希少タイプを任意に作ったり、固定割合へ強制配分したりするのは、診断妥当性を損なう。
- デザイン上の『SSRカード』と、現実の統計上の希少性は区別すること。全員SSR演出を見られる仕様なら『上位1%限定SSR』等の主張は不可。

## 実ユーザー分布を確かめるためのデータ契約
現行`MoneyPersonalityTelemetry.tsx`は、完了時の`sessionId`、`anonymousUserId`、`participantId`、`quality.jobCode`、`quality.primaryStyle`、`quality.axisStates`、`quality.cognitiveMode`、`quality.debugMode`、`quality.sourceUrl`、`startedAt`/`completedAt`を送る実装になっている。**GASで受信・保存されているかの実稼働は別途確認が必要。** 家計本体の銀行・金額情報を取り込まない。

実測で見るもの：
- 母数は有効な**ユニーク完了者**。再診断は別の安定性指標に使い、人口分布に二重計上しない。
- `cognitive=1`、`debug=1`、開発者・BOT・不正な回答を除外し、除外率を記録。
- JOB 8分布、STYLE 4分布、TYPE 32分布、JOB×STYLEの条件付き分布、3軸の相関、境界スコア別の分布。
- ソース別（X/Instagram/LINE/直接）・期間別の違い。URL全文を公開せず、必要な流入カテゴリだけ抽出する。
- 回答完了者だけの分布は**自己選択標本**。日本の人口割合とは同一視しない。
- 現状の完了ペイロードだけでは離脱分布の母数は作れない。離脱実測は別の許容されたイベント計測が必要。

## 公開画面での扱い方
1. **実測まではタイプ出現率・希少性バッジを非表示**。称号とJOB画像はタイプとして楽しめる。
2. 十分なデータが集まった時点で、例えば「直近90日・診断完了者N人のうちX%」の形で範囲とサンプル数を併記。目安としてユニーク完了者5,000以上かつ小分類の誤差幅を検証し、混合流入比率を確認する。
3. 95%信頼区間や順位の変動可能性を内部監査し、差が小さいのにレア順位を断定しない。
4. 成果指標はレア度の演出ではなく、本人共感度、隣接TYPEの識別、第2章への到達、ライフプラン相談予約確定への信頼維持。
