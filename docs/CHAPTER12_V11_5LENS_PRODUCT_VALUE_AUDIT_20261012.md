# 第1章×第2章「お金の性格、答え合わせ」V1.1｜5視点・実画面の商品価値監査

2026-10-12／**独立Draft PR #46・本番未採用**／目的：第2章の「実際の家計数字」と第1章の「自己認識」を正直につなぎ、その先の自発的なライフプラン相談への理解を助けること。

## 最重要結論

旧V1は「第1章で楽しさ重視」「第2章で娯楽費を大切にしたい」を並べるだけだった。本人が自分で答えたことを反復しただけで、「実際のお金の使い方の数字はどうなっているの？」という利用者の当初の問いに答えていなかった。

**新V1.1では、ルールで裏付けられた支出に限り、現在の月額と単純な12か月換算を併記する。** 例：ENJOY×守りたい娯楽費の架空ケース、入力月額24,000円／12か月なら288,000円。大切にしているものに、どの程度配分しているかを確かめるための**記述データ**であって、性格的中・適切額・ムダ・節約可能額・予測・勧誘の根拠ではない。サブスクの未使用分は総契約額と区別して表示。

この数字は第2章に既に存在する入力を別角度から見せたにすぎない。**「数字で性格の正誤が分かった」とは言えない。** 測定として新しい変数や第三者データを増やしていない。コピーが上手くなっても発見が実質ゼロなら不合格。

## 5つの専門視点

| 視点 | 旧V1の弱点 | V1.1の変更 | 残る未検証リスク |
|---|---|---|---|
| 行動経済学 | 同じ回答の言い換えでは行動の理由が生まれない。縦長の説明で結果閲覧を阻害 | 月額／12か月の名目支出を一画面の主情報に。根拠はタップ展開。無根拠時は小さいカード | 年換算が必要以上の危機感を与えないか。金額があるだけでは発見とは限らない |
| 心理学 | 「性格が当たった」という擬似確証と、合わない利用者への不必要な不安 | 結論は本人回答の関連。自己申告の明示、3軸的中率禁止、SECURE×保険でも相関を作らない | 金額によって自責・恥を感じないか。本人の優先順位を尊重できているか |
| マーケティング | 診断の続きを答える理由が不明、面談CTAとインサイトが切断 | 「何を守るか→どのくらい使うか→次に確かめること」の順に整理、C2本来の直接面談導線を温存 | 実相談のテーマは自動で具体化しない。面談数・適切性・満足への影響はゼロデータ |
| バズ | 性格＋家計の金額をSNSに流すとプライバシー漏えい | 既存の公開用JOBシェアと、非公開の家計答え合わせを完全分離 | 第2章の共有誘発力を増しているとは限らない。第1章の拡散成果と分けて測る |
| RPG世界観 | 第1章JOBの称号と第2章戦果が飾りで、冒険の説明が重複 | JOBカード直後／盾＝守る支出／ムダギリくんのチェックポーズ＋1件の結果→未鑑定宝箱につなぐ。重複コピーを削る | カードの厚みで戦果と宝箱が下に押される。1画面より長くなるならさらに圧縮 |

**自己採点はマーケティング文句にしない**：100点を目標とするが、採点根拠のない「現時点で95点」などは主張しない。条件を満たして初めて採用する。

## コード・実画面の重要な監査記録

- 先行公開のV1を、幅390pxで閲覧すると答え合わせ部分だけが約780px（ツールによるブラウザ測定。画面環境次第で差がある）に達し、第2章宝箱が後ろへ大きく押された。これは**不合格**。
- V1.1で反復説明、二重のデモ注意表示、大きすぎる余白を削減し、結果は月額／年換算と本人の次の確認に集中。ロジックも実支出0円の「守る」、負の金額、無限大などではカード発火させない。
- もとのV1試作には「0円なのに守る判定」という**現実の第2章エンジンでは起こらない架空フィクスチャ**があった。今回、非ゼロ支出・V5規則と整合しうるstatusで7ケースを修正。仮想の支出は実利用者の値でも統計平均でもない。
- 目的別の本人回答が揃わない場合、STYLEとの関連を作らない。性格の3軸（時間・判断・把握）は第2章の1回の入力で実証できず「的中率」を計算しない。
- 原寸の第2章戦果、確定改善機会／未確定の可能性、12カテゴリ図鑑、直接ライフプラン面談を保持し、ボタンや予約送信の変更なし。家計数字を性格専用GASにもシェア画像にも送信しない。

## 合格を判断する実験

**第2章の直後に5〜8名のCognitive Pilot：**
- 説明なしでカードを見て「新しく気づいたことは？」を自由回答。単に「性格が当たった」としか言わない、または自己申告の言い換えしか出ない場合は不合格。
- 「¥24,000／¥288,000 は何の数字？」と質問。予測・改善可能額・的中率と誤認すれば即修正。
- 「家計のこの使い方を自分では守りたい？見直したい？ なぜ？」と聞く。本人の価値判断を奪わない。
- 「次に確認したいことは？ 専門家へ相談したいことがあるとしたら？」を先に自由回答し、強引に面談を勧めない。
- 画面の最初→JOB→答え合わせ→宝箱→戦果→既存面談CTAまでの到達・スクロール・文字の読みにくさ・離脱を観察する。
- 被験者数5〜8人のCognitive Pilotは質的発見であり、CV上昇を証明しない。

**比較実験ゲート**：第2章V3.2の既存結果（答え合わせなし）と、答え合わせを追加した結果を比較。モバイルでの結果理解、1つの行動選択、自発的な次の質問、ライフプラン相談の具体的なテーマ、適切な実面談／開始者100人を別々に見る。反発・誤解・結果閲覧率低下があれば引き算または不採用。
