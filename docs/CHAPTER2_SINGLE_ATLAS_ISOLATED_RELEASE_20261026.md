- 冒頭の結果で**12カテゴリすべての敵／支出／負担率／判定／未確定候補**を一覧確認。4件だけ先に見せて残りが別画面に隠れる二重構造を解消。

- `confirmedA`は本人回答で確認できた改善機会、`cUpper`は未確定の確認候補上限。**統計差を削減額に加算しない**。共有画像に年収・本人支出を載せない。
- 任意の保障相談／無料ライフプラン相談とその予約完了は別のCV指標。LINE友だち追加だけでは予約確定ではない。
