# ムダギリ診断 第3章 V2.1｜2つの「人生の分岐」実戦ストーリーボード

2026-10-12。状態：**商品・会話UXの設計案。画面未実装、Cognitive Pilot未実施、未FROZEN。**

## 0. V2.0からの重要な修正

「20回の旅行」「1,040日の時間」はただの掛け算。数字が大きいだけで新発見と評価しない。

第3章が届けるものは **「同じ願いでも、本人が大切にする時期と守るものによって、選ぶべき準備・優先順位が変わる」** という気づき。目標や時期は必ず本人が選ぶ。人生の心配や家族構成を想像で加えない。

世界観：第1章「JOBを獲得」→第2章「12カテゴリを鑑定、守る盾と見直し候補を得る」→第3章「自分の未来の霧を晴らし、2つの道を比べる」。公式JOBは変えない。JOBで投資適性を推定しない。今の暮らしを大切にすることも正規の選択肢。

## 1. 第3章の3幕

**第一幕：未来の本当の宝物は何？** 第2章のgoalを引継ぎ、本人にとって欲しい暮らしや人生の時期を選ばせる。既に答えた質問は繰り返さない。

**第二幕：同じ願い、二つの進み方** 未来の価値を本人が選んだ単位で表し、分岐の違いを示す。年数・家族イベント・月額など未入力なら推測せず、計算なしの分岐だけ提示。リスクや損失を捏造しない。

**第三幕：本当に確かめたい条件を一つ見つける** 本人が選んだ分岐に沿って、第2章の守る支出、確認済み改善額、未確定候補を意味論どおりに再登場させる。本人用の未来攻略書は無料で完結。本人が望むなら「その2つの未来を、今の家計・資産・収入で比較するライフプラン面談」に進む。自動で個人情報を渡さず、共有内容を確認・同意できる。

## 2. 旅行の3幕｜「いつの旅行か」で準備が変わる

**根拠となる仮想回答：** 第1章は「直感魔導士」(イメージのみ)、第2章は「旅行」を選び普段の外食は守る。第3章でユーザーが「子どもが小学生のうちに、年2回家族旅行」「その時期はあと3年間」と答えた。家族構成・残り年数をシステム側から推測しない。

**T1 ムダギリくん：「旅行って、どこへ行くかだけじゃないよな。誰と、いつ行きたい？」**
選択肢：「子どもが今の年齢のうちに」／「家族と毎年ずっと」／「自分の好きなとき」／「まだ決めない」。最初を選ぶ場合だけ残り年数を尋ねる。不明なら不明のまま続ける。

**T2 霧が晴れる。「君が大切にしたいのは、いつでも同じ20回じゃなくて、まずこの3年間の機会なんだな。」**
本人が「あと3年」「年2回」を選んだ場合に限り、6回と表示。道A：年1回なら3回。道B：年2回なら6回。道C：年2回のまま旅行予算を変更して6回。1回20万円の入力がある場合のみA=3年間60万円、B=120万円。Cが15万円/回の本人選択なら90万円。単純名目予算、物価・支出の変化・実現可能性は未計算。

**T3 ムダギリくん：「ふだんの外食も大事なんだろ？ だったら削るものから決めるんじゃなくて、この6回をどう準備するか考えようぜ。」**
無料の1歩：次の旅行の時期と予算を決める。
ライフプラン面談の具体的テーマ：「外食を守りながら、あと3年間で年2回の旅行を目指す準備方法を、実際の家計と資金で複数比較する」。本人が比較したい場合のみ表示。

**重要な反証条件：** 本人が「子ども」「小学生」「残り3年」と答えなければ、そうした家族設定や「今しかできない」は絶対に出さない。画面の大きな数字が新発見を保証するとも言わない。

## 3. 働き方の3幕｜「いくら増やすか」から「いつ人生を変えるか」へ

**根拠となる仮想回答：** 第2章で「資産形成」を選択。第3章の本人の希望は「週5日から週3日に減らしたい」。55〜65歳と60〜65歳の2つの開始時期を本人が比較することを選択した。実際の年齢・収入・運用額は推定しない。

**W1 ムダギリくん：「NISAを増やすのは目的じゃなくて手段だろ？ それでどんな毎日をつくりたい？」**
選択肢：「週3日働きたい」／「転職する自由がほしい」／「まだ決めない」。週3日を選んだ人だけ勤務日数の比較へ。

**W2 二つの道が開く。**
A：55歳から週3日、55〜65歳の10年間で週5日との差＝約1,040予定勤務日相当。
B：60歳から週3日、60〜65歳の5年間で差＝約520予定勤務日相当。
52週／年×2日差の算術による差は520予定勤務日相当。休日・祝日・実労働・就業可能性は未考慮で、全て自由時間になるとは言えない。

月15万円の手取り収入差を本人が両方の道で同じと仮定した場合のみ、Aは10年間の単純収入差累計1,800万円、Bは5年間900万円。これを資金不足・貯蓄で相殺できる額と表示してはいけない。就業や生活費、資産、年金等を実際に比較する前の仮定。

**W3 ムダギリくん：「55歳から時間を増やすか、もう少し準備してから増やすか。同じ週3日でも、人生の作戦は違うんだな。」**
無料の1歩：「働く日数を変えた後の生活費と継続収入を、同じ基準で並べる」。
任意面談テーマ：「55歳から週3日か、60歳から週3日か。現在の家計・資産・年金・勤務条件で2案を比較する」。どちらかを勧誘せず本人が選ぶ。

## 4. RPGとして意味を持つ演出

- 第1章の公式JOB画像/STYLEを保持し、新JOBや架空の金融能力値を作らない。
- 第2章の守る支出は盾として、確認済み改善額は意味を守って表示。未確定の上限 cUpper は封印された宝箱で、使える金額として足さない。平均との差もムダ認定しない。
- 霧が晴れるのは「本人が二つの作戦の違いを理解できる瞬間」であり、開幕で羅針盤を授与しない。
- 結果の中心は「自分が望む暮らしと、選択した二つの道」。詳しい根拠や戦果内訳は補足で確認できる。
- 本人用の結果は無料で、SNS用には公式JOB・3章クリア紋章のみ。抽象的な未来のラベルは本人の明示許可時だけ。資産額・家族構成・希望年齢・診断IDを共有しない。
- 面談の導線は「この2案を自分の条件で比べる」。結果没収、LINE必須、恐怖演出、勝手な個人情報共有は禁止。第2章の直接面談導線も温存。
