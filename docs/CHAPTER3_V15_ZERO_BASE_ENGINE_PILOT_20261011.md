| 簡易数値計算 | EXPERIMENT | 必要条件を本人が入力した場合のみ。誤認や入力負荷を測定して採否判断 |

## 2. 独立プロトタイプ

- エンジン：`scripts/chapter3-insight-engine-v1.mjs`
- QA：`scripts/qa-chapter3-insight-v1.mjs`
- 再実行：`npm run qa:chapter3-insight` （Node.jsを使用）
- 実行環境：現時点ではコードとQAを隔離V8で実行。**GitHub Actions・ブラウザ・本番統合QAは未実施**。
- 結果：8目的地×4状態（32仮想ケース）、匿名ID不一致、JOB妥当性、金額意味論、簡易算術、共有の明示的選択など**203件PASS**。出力の心理的な新規性・金融適合性の証明ではない。

### 出力の種類と意味

| 種類 | 条件例 | 表示すること |
|---|---|---|
| `NEED_GOAL` | 第2章goal未引継ぎ、第3章でも未選択 | 目的地を選ぶ。未定も選べる |
| `GOAL_OPEN` | 未定を本人が選択 | 目標を強制せず近い用途だけ確認 |
| `DETAIL_MISSING` / `TIME_MISSING` | 未来の具体像や時期が不明 | 不足情報を一つだけ尋ねる |
| `VALUE_BRIDGE` | 本人が守りたいことを申告し、第2章にも「守る」支出がある | 価値の関係を提示。両立できるとは**断定しない** |
| `COST_UNKNOWN` / `PREPARATION_UNKNOWN` | 必要額または準備状況が未確認 | 次の確認点と、その理由を提示 |
| `PREPARED_SELF_REPORT` | 本人が検討済みと回答 | 強みを認め、妥当性まで保証しない |
| `SELF_DEFINED_QUESTION` | 本人が確かめたいことを明示 | その疑問を尊重する。回答を創作しない |
| `PLAN_NOT_VERIFIED` | 目標・時期・準備状況は自己回答上そろった | 必要なら任意で条件付き試算を案内 |

**共通ルール：** 「新しい気づき」を無理に捏造しない。リザルト内に「本人の回答」「第2章の診断結果」「条件付き計算」を区別して記載し、1アクションだけ強調する。

### 任意の算術

`optionalMath:{requested:true,targetYen:400000,earmarkedYen:40000,monthsUntil:12}` なら、追加で用意したい金額は36万円、月3万円。**無利息・運用益なしの単純割り算**であり、現状の家計で準備可能という意味ではない。

`cUpper`・`confirmedA`を計算の`earmarkedYen`として自動的に流し込むことは禁止。本人が明示的に「この目的に充当可能」と回答する別工程が必要。

### 共有

共有内容に含めてよい候補は、公式JOBコード・抽象的クリア紋章。**未来の目的地アイコンは`shareGoal:true`の明示的な選択時のみ**。本人の将来の希望の全文、家族、支出、資産、診断ID、相談テーマは共有しない。実装の際には明示的なシェア操作そのものも必要。
