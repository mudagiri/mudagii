## 統計と金額の一貫性：絶対条件
1. 全国・2024年・10歳区分・単身/二人以上・勤労者・**額面年収**を照合する。二人以上は申告者年齢が世帯主年齢に一致することも確認する。
2. 50万円刻みの元原表 `n>=50`、欠損・抑制表示除外、同一セルの費目平均支出/平均可処分所得を参照する。
3. 食費・光熱水道・日用品3費目も公式公表費目の完全同一範囲とは限らない。関連7カテゴリではアプリ側分類の「平均率」と**絶対に呼ばない**。
4. サブスク・自己投資は直接の独立公表セルなし。金額差 ≠ ムダ額 ≠ 確定削減額。FROZEN `confirmedA`、`cUpper`、行動アクション順位、GAS、LINE、共有画像金額に統計参考値を加えない。
5. 2025年の独立した年収階級データと2024年の同一交差表を混ぜない。2024年の階級列ずれ修正PR #82を前提とする。
