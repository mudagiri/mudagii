## 一次出典
- 総務省・2025年家計調査 家計収支編 二人以上の世帯 第4-2表（年間収入階級別１世帯当たり支出金額，購入数量及び平均価格）：
  `https://www.e-stat.go.jp/stat-search/file-download?fileKind=0&statInfId=000040409547`。対象：全国・二人以上世帯（就業状態を限定しない）、年収18区分、2025年計。
- 同単身世帯 第12表（年間収入階級別１世帯当たり品目別支出金額）：
  `https://www.e-stat.go.jp/stat-search/file-download?fileKind=0&statInfId=000040409846`。対象：全国・単身世帯、年収7区分、2025年計。
- **同じ統計表の所得階級別実測値は補助比較専用**。年齢・世帯人数・地域の別表から補正倍率を掛けてはならない（G03/G07）。あくまで年収階級による全国世帯の別視点。2025年間支出÷12で参考月額化し、契約型と確定改善額には加算しない。
- 第12表の単身「600万円以上」は所得帯の上限がなく、同じ年収1,000万円・1,500万円の固有統計ではない。集計サンプル小の場合の過度な精度感を避ける。

## 12カテゴリ対応判定（全件明示）

| 正本カテゴリ | 統計の元項目コード | 適用 | 原表対応の限界と対策 |
|---|---|---|---|
| 住居費 | 2（住居）/2.1（家賃） | 所得階級参考は現段階では未採用 | 第4-2表は持家を含む全世帯が分母。賃貸契約者の月家賃と直接比較不可。2023住宅・土地統計の**民営借家分布**を主基準のまま保持 |
| 通信費 | 7.3（通信）、7.3内の携帯通信料 | 未採用 | 端末代・固定ネット・家族分の範囲で合計が異なる。契約スコープが一致しない平均から確定削減額を作らない |
| 光熱費 | **3（光熱・水道）** | **単一公表セルの実測所得参考** | 電気・ガス・他燃料・水道を含み正本の対象範囲と一致。季節・地域・世帯人数の個別条件は未反映。追加の年収倍率は禁止 |
| 保険 | 生命保険等の契約項目 | 未採用 | 必要保障額・契約年数/範囲が違う。保障契約の内容評価と、既存JILI市場参考を主軸とする |
| サブスク | 政府統計に対応する総括品目なし | **正式AUDIT** | 動画・音楽・ゲーム月額・ジム月会費等の継続契約を一括する母集団一致の平均なし。停止/解約可能額を契約別確認 |
| 食費 | **1（食料）** | **単一公表セルの実測所得参考** | 家庭内食品+外食等。所得帯別の別視点として使用。所得階級平均と世帯人数基準を掛け合わせない |
| 日用品 | **4.4（家事雑貨）＋4.5（家事用消耗品）** | **同一表・同一列の実測品目合算** | 家具・電化製品（4.1等）は除外。二つの年間平均金額を加算して月額化。これは公表「日用品」単独平均ではなく当プロダクトの厳密な定義に合わせた集計 |
| 娯楽 | 9（教養娯楽）、10.3（交際費）など | 未採用 | 大分類9にはサブスク月会費、成人自己投資等の他カテゴリ所有が混在。10.3も交際の細分割が必要。二重計上を回避できる品目対応表が完成するまで総計所得平均を表示しない |
| 美容・服飾 | 5（被服及び履物）＋10.1.1（理美容サービス）＋美容用品の指定品目 | 未採用 | 10.1.2（理美容用品）には日用衛生品が混在。性別×年代モデルも存在するため、品目別所有の明確化まで未採用 |
| 車関連費 | 7.2（自動車等関係費） | 未採用 | 自動車購入・保有台数や非保有者を含む分母が違う。購入と維持・保険・燃料は別。保有世帯に固有の適正額を捏造しない |
| 教育費 | 8（教育） | 未採用 | 子のいない世帯も分母に含み、子1人×公私×学齢で比較する正本と母集団が一致しない。文科省・子供の学習費調査の子別基準を保持 |
| 自己投資費 | 訓練費・講座費等 | **正式AUDIT** | 成年者の目的/成果/利用状況に依存。全国平均を適正価格として生成しない |

## 公開に入れた独立の所得参考・件数
- `income-class-food-reference-v1.ts`：食費（第4-2表/第12表）
- `income-class-energy-reference-v1.ts`：光熱費（第4-2表/第12表）
- `income-class-daily-reference-v1.ts`：日用品（4.4＋4.5、**同じ原表/同じ所得列の合算**）
- 2人以上：回答済み世帯年収帯のみを使用、診断範囲が「家全体」の場合に限定。単身：診断リザルトの任意入力のみ。どちらも入力した月手取りから額面年収を推測しない。
- `qa-income-class-food-reference-v1.ts` / `qa-income-class-energy-reference-v1.ts` / `qa-income-class-daily-reference-v1.ts` を全て回す。
- **判定・改善額・未確定上限・シェア金額・GAS記録は変更しない**。正本の比較を劣化させることなく、単一の「所得×世帯人数×年齢×地域」の架空全国平均も作らない。
