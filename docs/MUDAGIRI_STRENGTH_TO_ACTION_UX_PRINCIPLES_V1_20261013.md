# ムダギリ診断｜「強みを見つけて、今日できる一歩へ」UX原則 V1

2026年10月13日制定。第1章・第2章・今後の第3章をまたぐプロダクト思想。**数値・診断ロジックの仕様変更ではない。** 第1章（お金の性格）と家計診断本体V1 FROZENは維持する。

## コンセプト

**「できていないことを責めず、今できていることを認め、これからできることを一緒に見つける」。**

お金を節約すること自体をゴールにしない。資源を守り、本人の大切なことと結びつけ、望む未来の小さな行動に変える。相談の最終CVはライフプラン面談の**成立**。LINEの友だち追加や外部遷移は面談成立と区別する。

参考となる読み物：
- ダイヤモンド社書籍編集局（2026-10-11）『「老後にダントツで後悔すること」・ベスト1』。先送りした「いつか」を今日できる小さな行動に変えるという考え方。
- 同（2026-10-11）『なぜか人生がうまくいかない人の特徴・ワースト1』。できないことだけを数えず、今できることから着手する考え方。

記事の「ベスト1」「ワースト1」を母集団に基づく統計順位と見なさない。学習性無力感その他の医学・心理学的な状態をユーザーへ推定・診断しない。著者の表現を長く引用せず、自分たちのUX原則として要約する。

## 4視点の100点基準（仮説と検証を分ける）

1. **行動経済学**：多数の候補に圧倒されないよう、上位一件の確かめ方を具体的に示す。損失回避・将来不安をいたずらに刺激しない。根拠は初期表示。
2. **心理学**：能力へのレッテルを貼らず、`protect/ok`という実データがあれば肯定する。誰でも同じ内容を褒める空虚なパーソナライズはしない。本人の選択権・断る権利を守る。
3. **マーケティング**：「自分を知る→確認できる事実がある→未来の相談が役立つ」という因果をつなぐ。CVは予約／面談成立に向けた適切な動線と実測。LINE追加を相談成立として計上しない。
4. **バズ理論**：共有したくなるのは数字で煽ることより、自分のJOBに愛着が湧くこと。SNSカードに家計金額・契約内容・年収を載せない。暗いRPGギルドと楽しいJOBを統一する。

「100点」は絶対評価ではなく、確認すべき品質目標。高評価の主張には、定量指標と本人理解テストの根拠を要求する。

## 表示文言ルール

- **使える**：「これは守っていい」「確かめてから決めよう」「全部を直さなくていい」「今できることを一つ」「いつかやりたいこと」。
- **禁止**：「あなたの人生は失敗する」「老後に必ず後悔」「今すぐ申し込めば○万円得する」「平均より高い＝ムダ」「この性格なら節約できる」「古い保険は無意味」。
- 同じ価値を述べる説明カードやCTAを複製しない。結果の最初の数画面ではJOB→ムダギリくん→金額の意味→根拠が優先。1か所に一つの視覚的主役。
- 未確定の潜在額 `cUpper`は参考上限。Confirmed `confirmedA`のみ確認できた改善額。支出の保護も戦果であり、削減額と合算しない。

## リリース・計測チェックリスト

- 第1章の正本JOB／STYLEと第2章で一致する。第1章の記録がない場合は捏造しない。
- `protect/ok`の肯定的な会話は実際の判定行があるときだけ。ゼロ候補でも何もない人とラベルを付けない。
- 候補額・理由・確認方法はタップ前から見える。保障は保険料だけでなく治療の変化なども扱い、独立した公式LINE相談へ。保障内容が確定しない場合は断定しない。
- ユーザーの情報を含むSNS共有カードを作らない。第1章・第2章の世界観は共通でも、装飾の追加で主CTAの可視性を落とさない。
- Chrome/WebKitの320/375/390/430px・SSR・公開SHA・実際のスマホの見え方を検証。実LINEトーク送信と分析シート照合は別の人間によるゲート。
- 定量KPIは結果到達率、全候補理解率、シェア完了率、LINE遷移・相談文コピー率、面談予約率・面談実施率。5〜8名の認知テストでは「何が確定／未確定か」「次に1つやること」「相談は任意か」を自分の言葉で説明してもらう。
