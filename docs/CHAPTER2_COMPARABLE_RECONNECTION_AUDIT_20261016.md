# 第2章｜比較基準再接続監査（2026-10-16）

## 正本の優先順位
1. 最新の12カテゴリ契約 `MUDAGIRI_12CATEGORY_FINAL_DATA_CONTRACT_V1_0.xlsx` を正式な意味論・データ型の正本とする。
2. `Mudagiri_Reference_Data_V1.0_FINAL_FROZEN.xlsx` は**旧世代の参考資産**。年収・年齢・地域別係数や `income_man` があるが、複数の独立した統計表の積を「その属性の公的な直接平均」と見なしてはいけない。
3. 現行 `comparable-resolver-v2.ts` の値・根拠・適用条件をカテゴリごとに照合し、直交属性の補正には `MODEL` と根拠を表示する。公式クロス表のない属性を勝手に掛けない。

## 監査で判明したこと
- 単身世帯の食費・光熱費・日用品・娯楽等は、年齢帯で参照値を選ぶため、**年収450万円と1,500万円で同じ値**になる。単身年収別の公的統計（旧資料の2025家計調査第12表）は存在するが、最新12カテゴリと分類の適合・表の再検証を済ませていない。
- 複数人世帯の食費・光熱費・日用品・娯楽には、`resolveComparableV1` の年収係数が `incomeFactor` として掛けられる（年収500万円以上）。この比率は世帯人員・季節・地域別の2025参照値に後付けされるため、**直接観測された「35歳・4人・東京・年収900万円」の平均ではない**。
- その補正を含む `food` 等が `confidence:'DIRECT'` のままになっている箇所があり、UI上の根拠強度を過大に表示する危険がある。比較値の正しさとは別に、出典分類の監査が必要。
- `income-burden-lens-v1.ts` は「本人が入力した月手取りに対する本人の支出率」であり、「同じ所得階級の平均負担率」ではない。平均と誤読させない。
- `AUDIT` カテゴリに架空の平均を作らない。住居・保険・通信は対象範囲や契約単位を確認し、平均との差を確定改善額へ自動加算しない。
