# 第2章V3.2｜リザルト「比較条件の確認・変更」統合監査（2026-10-22）

## 結論
入口プロフィールで年齢・世帯・額面年収帯を回答した場合、リザルトは**年収の再回答を求めず**、比較条件の単一サマリーを表示する。任意の変更はサマリー直下の**一つの折りたたみ「比較条件を変更」**から。家計年収1,000万円以上の細分化も同じ編集領域内に限り表示する。

### UI
- `PEER_COMPARISON_CONDITIONS_SUMMARY`: 年齢・世帯区分・額面年収を一行で表示。プロフィール由来。本人年齢=世帯主年齢・勤労者世帯の一致は未確認なので、「公式の同条件平均」として**無条件には扱わない**。
- 単身 `SINGLE_INCOME_CLASS_OPTIN`: 既入力年収は選択済みのまま、編集は**折りたたみ初期閉**。不明のとき「比較条件に年収帯を追加する（任意）」。変更はリザルト内のみ。
- 二人以上世帯全体 `MULTI_PEER_CONDITION_EDIT`: 額面年収の大枠編集と1,000万円以上の細分化を**単一編集パネル**へ統合。1,000万円以上の細分類を勝手に選ばない。大枠の変更時には旧細分類を破棄する。
- 既存 `MULTI_PEER_HEAD_AGE_CONFIRM` と `PEER_WORKER_STATUS_CONFIRM` は維持し、公式統計で比較可能な本人=世帯主年齢・勤労者・n>=50・公表同セルのゲートを変更しない。
- `comparisonProfile` は画面表示にのみ使う不変の一時コピー。個人の月手取り、家計診断ロジック、`confirmedA`、`cUpper`、GAS、LINE、シェア金額、1章JOB/STYLE、第3章には変更しない。
- 400万円未満単身等、観測した公式母集団が欠ける場合に架空の平均を作らない。任意で他区分に変更したときは旧の未対応注記を引きずらない。

## 4視点の監査と現時点の合格基準
|視点|問題|改善|未完了の実測|
|---|---|---|---|
|行動経済学|結果に再度年収を尋ねると質問の重複・選択負担が発生|入力情報をデフォルト再利用。任意変更のみ開く。Hickの法則に沿って独立年収操作を一本化|結果閲覧率と条件編集率|
|心理学|年収を再確認されると「診断が回答を覚えていない」という不信感|「今回の比較条件」を先に見せ、属性確認が必要な理由を明記。無回答を許容|年収回答拒否率と納得度|
|マーケティング|統計の設定操作が本来の比較・相談導線を隠す|比較条件サマリー＋任意編集をカードの冒頭に集約。12カテゴリ・相談CTAは維持|カード到達率・面談**予約完了**率|
|バズ理論|「同条件平均」を盛ると共有時の誤認・炎上を招く|原表セルの一致ゲート／公式関連費目の範囲注意／節約額不算入を維持|シェア率と出典への疑問の発生率|

**100点判定は実測とiPhone実機チェックまで保留**。自動ブラウザQAが通ってもユーザーの体験スコアや予約CVは証明されない。
