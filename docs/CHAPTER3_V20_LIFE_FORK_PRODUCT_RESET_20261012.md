# ムダギリ診断｜第3章 V2.0 コンセプト再設計
## 「ムダを斬った。その先、何を増やす？」――人生の分岐地図（未実装・未FROZEN）

作成：2026-10-12。ステータス：**戦略・体験コンセプトの再設計。V1.7の本番統合は停止。** 本書は設計案であり、実ユーザー検証の実績ではない。

## 0. V1.7に対する明確な不合格判断

ユーザー評価：「行動経済学、心理学、マーケティング、バズ理論、ムダギリの世界観とCVはライフプランの面談。全然魅力的な第3章になってない」

実スクリーンショットを確認。旧版は未来の羅針盤を先に「獲得」し、その下で数字の入力→計算→注意事項→一般論→任意相談。これは**RPG装飾付きの簡易計算フォーム**。第1章JOBは飾り、第2章戦果は見直し候補を再掲するだけ、面談は最後の汎用CTA。前版の技術的QA成功を商品価値の成功として扱わない。

### 何が足りないか

- ユーザーが**本当に増やしたい人生のもの**が分からないうちに、金額の話を始めている。
- 得られた数字が本人の望み・行動選択に変わる前に「報酬」を渡している。
- 第1章→第2章→第3章で解いてきた問いが、**一つの発見へ収束していない**。
- 診断だけでできることと、ライフプラン面談で解くべき具体的な意思決定が分かれていない。
- バズはJOBカードの装飾だけ。「自分にもこの未来があり得る」と友人に語りたくなる結果がない。
- 注意事項が連続して読みにくい。金融上の注意を隠さず、段階的に表示する必要がある。

## 1. ゼロベースの商品仮説

**第1章：どんな冒険者か。第2章：何を守り、何を見直せるか。第3章：その戦果で、人生の何を増やしたいか。**

第3章の主役は「資産形成」という言葉ではない。**時間／体験／安心／選択権**。人が望む未来の価値を、本人が選んだ単位で見せる。ただし、過去のJOB・STYLEだけで本人の価値観を自動推定しない。ユーザーが選ぶ。

正式検討名：**第3章「人生の分岐地図」**。前版の「未来の羅針盤」は報酬アイテムとして残しても、最初に渡さない。

メインコピー案：**「ムダを斬った。その先、何を増やす？」**

世界観：第2章で戦った12カテゴリの敵は「何を見直せるか」。第3章の新たな敵は人ではなく、**「先が見えない霧」**。ムダギリくんが一緒に霧を晴らす。人格や貧困を敵扱いせず、安心・今の幸せも正規の選択肢として守る。

## 2. 未来の3幕（質問票でなく、選択が見える物語）

### SCENE 1｜霧の向こうで、何を増やしたい？

- 入力：第2章で選んだgoalを引き継ぎ、変更可能。目的地は既回答なら再質問しない。
- ゴール別に「何を望んでいるか」の場面を提示し、**1つ選ぶ／まだ決めない**。
- 例：旅行→「家族で出かける回数」「自分の趣味の時間」「気軽に旅立てる自由」。
- 例：資産形成→「55歳から働く日数を減らす」「不安なく転職する自由」「選択肢を手放さない」。
- ムダギリくん：「お金を増やすのは手段だろ？ その先、どんな毎日が欲しいんだ？」

### SCENE 2｜未来の宝物を、本人の単位で数える

**円だけを使わない。** 願いに合う生活上の単位を、必要最小限の条件で計算する。

- 旅行：ユーザーが年2回と10年間を選んだら、「**これから20回の家族旅行**」。1回の費用を本人が選択・入力した場合だけ必要資金の条件付き目安へ進める。
- 働き方：現状週5日→希望週3日、55〜65歳の10年間と本人が選んだら、52週/年が続くと仮定して「**働く日数の差：約1,040日**」。**それが全て自由な休日になるとは限らない。** 条件の整理（雇用、祝日、実稼働、収入の変化）が次のテーマ。
- 備え：本人が現金と基本生活費を選択・入力した場合のみ「**生活費何か月分を賄えるか**」の算術。保障の十分性は断定しない。
- 目標未定：日々を守りながら選択肢を残す未来。根拠がない数量を作らない。
- この場面での「ハッとした」は**仮説**。本人が既に知っていたら新発見と強要しない。

### SCENE 3｜未来の分岐地図（手段を比べる）

ユーザーが選んだ価値、本人が守りたい支出、第2章の状態を並べて、**2〜3つの実際に考えられる作戦**を表示する。これは将来予測ではなく、条件を試すシナリオ比較。

旅行例：
- 作戦A：年1回／10年で10回。1回予算があるときのみ金額計算。
- 作戦B：年2回／10年で20回。必要資金と第2章の確定改善／未確定候補を別々に表示。
- 作戦C：年2回のまま、1回の予算を変更して比較（本人が選んだ時だけ）。
- **本人が第2章で「守る」と判定した外食を削るルートを勝手に作らない。**
- 「見直し候補12,000円」のようなデモ値を本人の準備済み資金と偽装しない。`cUpper`は未確定、`confirmedA`も実際に現金で準備済みとは限らない。
- 数字が不足する場合は、**比較に必要な変数1つ**と、その理由を提示。実現可否の断定はしない。

仕事を減らす例：
- A：週5日のまま将来の貯蓄を優先
- B：55歳から週4日を希望
- C：55歳から週3日を希望
- 期間から「仕事日数の差」を条件付きで示す。ただし、給与・年金・その他資産・生活費等がないと費用差は**未判定**。「◯万円不足」とは断定しない。
- 第1章JOBは不変。「性格がこうだからBがおすすめ」とは言わない。

**報酬のアンロック条件**：「本人が何を増やしたいか」＋「自分が比べたい作戦がある」＋「一つの次の確認ポイントを知る」。これを満たしたら未来の地図が発光し、羅針盤を授与する。数字がなくても、選択権の可視化で成立する場面はあるが、本人の新規性を未検証のまま「発見成功」と呼ばない。

## 3. その人が本当に得るリザルト

1. **一行の本人の願い（本人の回答に基づく）**：「10年間で家族との旅行の機会を20回つくりたい」
2. **選んだ分岐を比較する地図**：例10回/20回、費用条件は入力された場合のみ
3. **第2章から持ってきた「守る盾」「確認済み戦果」「未確定の宝箱」**（意味論厳守）
4. **その未来を考える際に一つ足りない情報**：例「旅行を続けられる年間の準備予算」
5. **自分でできる次の一歩**：決める・確認する・書き出す、のいずれか1つ
6. **未来の羅針盤**：この内容が見えて初めてクリア演出
7. **任意の未来作戦会議**：本人が選んだ分岐を元に、自分専用のライフプランを検討する

結果の画面上部には「羅針盤を獲得」ではなく、**本人が選んだ未来の内容**を最大の文字で置く。折りたたむのは根拠の詳細と注意書きの補足。安全に必要な注意書きは数字のすぐ横にも表示する。

## 4. CVを「最後のボタン」から「作戦の続き」に変える

**最終CV：ライフプラン相談の有効な実面談。** 高い予約クリック率は目標ではない。

- ユーザーが相談したい場面だけ「**あなたが選んだ2つの未来を、今の家計で比較する**」と表示する。
- 相談では何を行うか約束を具体化：本人の希望→生活費/既存資産/使う時期の確認→代替シナリオの比較→本人が判断できる形で選択肢と注意点を整理。特定金融商品を売るための診断だと誤認させない。
- 無料の自己実行アクションを**必ず同時提供**。「相談しなければ結果を没収」は禁止。
- 自動で相談員へ家計数字・タイプ・個人的希望を送信しない。事前にプレビューした共有内容に、本人が明示的に同意した場合のみ送信。
- 第2章の直接相談導線は残し、3章経由の面談との実施・適合性・本人満足を区別して検証。

CTAコピーの具体例：

- 旅行：「**今の外食を守りながら、年2回の旅行を続ける3つの家計プランを比べる**」
- 働き方：「**55歳から週3日勤務にする場合の、生活費と収入の組み方を一緒に整理する**」
- 家族：「**教育費の時期と今の暮らしを両立する準備を整理する**」
- 未定：「**将来の選択肢を残す資金の置き方を整理する**」
- 条件不足なら面談で何を確認するかを具体的に示し、資産計画が成立するとは言わない。

## 5. バズを「診断結果の自慢」から「会話のきっかけ」に変える

本人専用レポートは資産・生活・将来の詳細があり、**そのままSNSに出さない**。

共有カード：
- 公式JOBキャラクター＋クリア紋章＋「ムダを斬った。その先、何を増やす？」というブランドコピー。
- 本人が**公開を選んだ場合だけ**「未来の宝物：時間／体験／安心／選択権」の抽象ラベル。「家族との20回の旅行」のように特定情報は本人が意図しても、最初の共有では原則省く。
- 金額、年収、支出、家族属性、診断ID、相談テーマ、URL内の個人データは一切含めない。
- 「友だちにも、どの未来を選ぶか聞いてみたくなる」自然な話題性を検証。共有しなくても全機能が使える。
- シェアCTAは1つを主に。X/LINE/Threads/Instagramの重複UIを整理。

## 6. 8目的地に同じ文章をコピペしない

| 第2章goal | 第3章で増やすもの（本人が選択） | 比較に使える具体的な単位 | 主な未確認変数 |
|---|---|---|---|
| 住まい | 毎日の時間／暮らしの安心 | 通勤時間の差、転居後の住居費 | 現在/希望条件、物件費、期間 |
| 家族・教育 | 一緒に過ごせる時間／選択肢 | 学費支出の時期別重なり、準備期間 | イベント年と必要額 |
| 旅行・趣味 | 体験の回数／大切な時間 | 年間回数、今後の機会数、予算 | 回数、期間、1回予算 |
| 資産形成 | 自由に選べる働き方／安心 | 勤務日数、手取り収入差、使うまでの年数 | 本人の自由の定義、期間、継続収入 |
| 独立・挑戦 | 挑戦する機会／生活を守れる期間 | 初期費用、生活を維持できる月数 | 実際に使える資金、月額生活費 |
| もしもの備え | 守れる生活の時間 | 必須生活費を賄える月数（条件付き） | 使える現金、支出、既存の保障 |
| 老後 | 自由な時間／生活の安心 | 働く日数、退職後の期間、収支の条件 | 希望生活費、年金等の継続収入 |
| まだ決めていない | 将来の選択権 | 近い用途と長い用途の資金の区分 | 現在の予定と利用時期 |

8目的地の全てに「数値でハッと」を捏造しない。意味のある比較が作れるものからPilotし、それ以外は設計し直す。「分からない」を失敗扱いしない。

## 7. 5視点の採点で必ず確認すること

| 視点 | この案の仮説 | 合格を判断する証拠 |
|---|---|---|
| 行動経済学 | 人生の単位を先に見せることで遠い未来が具体化し、比較選択に参加したくなる | 選択操作、完了率、回答時間、既質問の重複、情報過多への苦情 |
| 心理学 | ゲインを先に自分の言葉で選ぶと、本人が大事にしたい未来と手段を結びつけやすい | 自由回答で自分の発見を話せるか、心理的圧迫感、納得度 |
| マーケティング | 「面談で比較する自分の2案」が決まると、一般的な無料相談より有効面談に意義ができる | 実面談/開始者数、面談の適合性、満足、対照との比較 |
| バズ理論 | キャラ＋人生の価値観という共有可能なシンボルで、友人に試してもらいたくなる | 実共有、受信者の開始率、過剰開示・後悔・重複導線 |
| RPG連続性 | 同じ主人公が第2章の戦果と守る盾を使い、霧の地図の分岐を開くと、3章が一つの物語になる | JOBと背景の統一、12カテゴリの意味維持、ユーザー自身の物語としての認識 |

これは**検証仮説**であり、心理学理論やビジネス成果が保証されるものではない。

## 8. この案を実装する前の反証テスト

- V1.7と新案の**文章・操作可能な2画面モック**を先に並べ、「新案でも結局自分の答えを言い換えていないか」を監査。
- 5～8人のCognitive Pilotで「診断開始前に知りたいこと」を記録。結果を見たあと、**誘導せず自由回答**で「初めて考えたこと」「実際にやれること」「誰かに相談するなら何を確認したいか」を尋ねる。
- 価値がなければV2でも不合格にする。数字を見せて興奮させるために資産不足・危機・ライフイベントを捏造しない。
- 技術QAとは別に、ユーザーが「計算フォームを入力させられた感じ」「相談へ誘導された感じ」と答えたら課題として扱う。
- 第1章・第2章のFROZENデータ契約、匿名ID・Goalの引継ぎ、途中復帰、プライバシー、直接相談導線を本番実装前のゲートにする。
- 広い8ゴール全面実装・演出の磨き込み・本番マージは、このプロダクト価値の確認まで**停止**。
