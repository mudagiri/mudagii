## 0. 結論 — 100点に見える診断ではなく、100点を検証できる診断

**不合格のまま設計を進めない項目**：
1. 第1章JOB/STYLEを活用した個別の「納得」はあるが、金融商品・稼得能力の適性と混同していない。
2. 第2章12カテゴリの\`protect/inspect/optimize/cut/ok/na\`、A（条件確認済み見直し機会）、C（未確定候補）を正しい意味で使う。**Aも実行済みの貯蓄ではない。Cは資金ではない**。
3. 第3章で聞く「目的地」「叶えたい時期」「必要時の1問」には結果を変える独立の情報価値がある。
4. 第1章と第2章の質問を繰り返さない。第2章の\`goal\`は選択済みなら明示的引継ぎ後に確認。無ければ選択。
5. **稼ぐ・育てる・整えるの3つの固定ラベルに閉じ込めない。** 目標・現実条件・情報不足によって一手を変える。
6. リザルトは「新しい関係性の気づき」→「今日できる一歩」→「面談では何を整理できるか」。相談予約は共通CVだが、相談テーマは本人に合わせて編集可能。
7. バズは匿名の冒険者キャラ／旗／旅路。家計・借入・医療・弱点・収入推定・相談理由をデフォルトでSNSへ載せない。
8. **背景・キャラ・イベント透過素材は内容が承認されてから別制作**。アプリUI全体を1画像に焼き込まない。第2章の世界観に揃える。

**最重要の編集上の変更**：Draft 0.7でNO-GOだった「収入アップ」「資産形成」を、全員に質問を増やすのではなく**異なる回答が異なる初手を生むときだけ1問追加**して検証する。成功しなければ「あなたに向いている道」の断定を諦め、本人が必要情報を確かめる実用的な結果に戻す。

## 1. 4視点×25点＝100点の採点ルーブリック

各視点に5項目×5点。採点単位は**各イベント／リザルト／第1〜3章の通し体験**で、ある1画面のデザインが優秀でも通しの得点に転記しない。評価者2名の独立レビュー＋ユーザーCognitive Pilotの証跡を残す。実測前は**「未採点」**。

得点の読み方：
- 0＝要件欠落／明確な不具合。
- 1＝概念だけ／不適切な誤解を生む。
- 2＝草案あり／根拠・一貫性が弱い。
- 3＝コピー・状態分岐・設計レビューで整合確認。
- 4＝操作プロトタイプのQAと観察評価で大きな問題なし。
- 5＝運用・ユーザー検証で採択基準を満たし、再現性を確かめた。
（※テスト規模が小さい場合は4〜5点の確証は限定的。合計100は自動的に付与しない。）

### ① 行動経済学／25点
| 5点項目 | 判定証跡 |
|---|---|
| A1. 意思決定の摩擦 | 第2章で回答済みなら重ねて聞かない。必要な操作だけ。E3は最大1問 |
| A2. 選択の理解容易性 | 選択肢の粒度を統一。「正解」「おすすめ」で特定回答に誘導しない。未定を許す |
| A3. 反応の一貫性 | 選択すると地図の旗／時間軸／道筋が変わり、戻る操作で整合する |
| A4. 小さな行動への接続 | 今日できる行動が1つ、実行対象・動詞・必要時間の目安が具体的 |
| A5. 選択の自由 | 面談なしでも結果と一手を持ち帰れる。登録強制や隠れた不利益がない |

### ② 心理学／25点
| 5点項目 | 判定証跡 |
|---|---|
| P1. 当たっている感の根拠 | JOB/STYLE・第2章事実・第3章選択が真に関係するときのみ説明 |
| P2. 答えの復唱を超える新規性 | 「Aより先にB」「Aを守りながらB」など、自分の未整理の関係が見える |
| P3. 自律性・自己効力感 | 苦手・未定・資金不明を低評価にせず、選び直し可能 |
| P4. 不確実性を正直に示す | 本人申告／確認済み／未確定／不明が見分けられ、誤断定がない |
| P5. ムダギリくんの人間味 | 命令・説教・上からの称賛を避け、仲間として短い会話をする |

### ③ マーケティング／25点
| 5点項目 | 判定証跡 |
|---|---|
| M1. 結果の即時価値 | 診断終了後すぐ「自分にとって何が重要か」が理解できる |
| M2. 面談で得られる価値の個別化 | 住まい／挑戦／収入／資産形成等、実際に対応可能な範囲に限定 |
| M3. 単一CVの明快さ | 主CTAは原則1つ「この作戦を相談する」。テーマ変更可。LINE追加≠予約確定 |
| M4. 第2章との共存 | 第2章の直接面談CTAを維持。第3章任意化で予約総数を毀損しないか計測 |
| M5. 実際の成約につながる質 | CTAクリック・LINE遷移・日程確定・実面談・本人期待一致を別イベントとして計測 |

### ④ バズ理論／25点
| 5点項目 | 判定証跡 |
|---|---|
| V1. 固有性 | 既存正本JOB画像・本人の旗・時間軸・地図の視覚が一貫して個別化 |
| V2. 共有したくなる成果 | 「未来の航路が開けた」「こんな冒険者だった」が数秒で伝わる |
| V3. プライバシー | 気になる障害、家計金額、負債、職業収入、相談内容をシェアから除外 |
| V4. シェア実行の摩擦 | 端末の共有UIと画像保存、テキストリンクに過剰な重複がない |
| V5. 第1〜3章の物語継続 | 第1章JOB→第2章戦果→第3章航路が同一RPGだと伝わる |

### 点数とは別のNO-GO（1つでも違反したら100点でも不採択）
- 別匿名IDのJOB/家計データを混ぜる／第2章12カテゴリの欠落・重複に気付かない。
- \`cUpper\`や同条件平均との差額を「貯蓄済み」「必ず削減できる」「投資可能金額」と表現。
- 実行未確認の\`confirmedA\`を現預金の増加と扱う。
- ファンタジー選択だけで金融商品・損失許容度・収入アップの可能性・職業適性を断定。
- 目標を第2章で選んだのに無条件で再回答させる。または本人同意なしにLINE等へ家計情報を送る。
- 受け付けられない相談分野の解決を保証、LINE追加だけで予約済みと扱う。
- 第1・第2章FROZENの診断ロジックを無断で変更。
- 強制的な待ち時間・誤操作不能・重要文が背景に埋もれて読めないなどアクセシビリティの重大な欠陥。

## 2. NO-GOだった「収入アップ」のリザルトを再設計する

### 本質的な問題
第1章のSTYLE OPTIMIZEや第2章のサブスクAと、本人が「収入を増やしたい」と思うことの間に**直接の因果関係はない**。その間を「性格だから稼げる」「支出を整えたから増収できる」と埋めると虚偽になる。前章の事実は**何を守り/まだ確定していないか**の説明へ限定し、収入増の具体経路は本人の現実の手掛かりで絞る。

**新しい条件付きQ3（目的地＝収入増で、現実的な第一手が分岐するときのみ）**：

> 【分かれ道：武器になるものは？】
> ムダギリくん「収入を増やしたいんだね。仕事の道はいくつもあるけど、今、手がかりになりそうなのはどれ？」

| code | 選択肢（自己申告） | 一手の変更（**就職/収益を保証しない**） | 面談で整理できる価値 |
|---|---|---|---|
| \`atWork\` | 「今の仕事に、評価や昇給の道がありそう」 | 「次の評価で給与が変わる条件を一つ確認する」 | 今の仕事の昇給条件と目標収入を比較 |
| \`outsideDemand\` | 「仕事の外でも頼まれた経験がある」 | 「頼まれた仕事内容と、かかる時間を一件メモする」 | 社外活動を増やす場合の時間・対価・制約 |
| \`learningTime\` | 「新しいことを学ぶ時間ならつくれそう」 | 「身につけたい技能を使う仕事例を1つ調べる」 | 学習にかける時間と収入目標の条件 |
| \`unverified\` | 「まだ手がかりが分からない」 | 「今の仕事で給与が変わる条件を一つ調べる」※本人の環境により別案を提示 | どこに選択肢があるかを整理 |

**主な対照テスト**：同じC1/C2/収入増/時期でもQ3回答を変えると、上記一手・地図のルート・相談で明らかにする条件が変わる必要がある。これは**「適性が変わる」のではなく「最初に調べる対象が変わる」**という差。

**原稿候補（架空ユーザー、\`outsideDemand\`）：**

> **未来の作戦書｜収入の道**
>
> **仕事を増やす前に、「すでに求められたこと」を見てみよう。**
>
> 1〜3年で収入を増やして、できることを広げたい。しかも、仕事の外で頼まれた経験があるんだね。なら、まずは新しい仕事を探すより、そこで**何を頼まれ、どのくらいの時間が必要だったか**を確かめてみよう。
>
> 第2章には条件を確認できた見直し機会もあるけれど、それは実行できた現金とは別。収入の道は、実際の仕事の条件から見ていく。
>
> **今日の一手：** 直近で頼まれた仕事を一件だけ、内容と必要時間でメモする。
>
> **相談すると：** 今の仕事・社外活動・使える時間のどこに改善の選択肢がありそうかを整理できる。
>
> **この作戦を相談する →**

**判定：改善候補（まだ100点ではない）**。本人の一回答で最初の行動を個別化できるが、本人の知らなかった真実を見つけたとは限らない。支出Aは主提案に効いていないので、**第2章結果をただの装飾として長々と差し込まないこと**。C2に価値を守る強い根拠がないケースは収入改善の面談テーマへ重点を置き、前章から引き継ぐのは正本JOB/STYLEと変化のない家計事実の尊重にとどめる。

**次のP0改善課題**：この場合、第3章は「稼げる額」を知らない。稼ぐ力が本当に伸びる可能性を判定しているのではなく、**増収につながる現実の選択肢を検討し始める**ことを提供する。ライフプラン/キャリア面談で何が扱えるか、担当者のサービスメニューを確定する。

## 3. NO-GOだった「資産形成」のリザルトを再設計する

### 本質的な問題
「資産形成したい」「近い未来に叶えたい」の2回答では、**どの資産に投資できるかも、いくら使えるかも分からない**。本人の使途が先に分かれば、**「未来に向けて増やすお金」と「近く使うために守るお金」**という別の意思決定を示せる。

**新しい条件付きQ3（目的地＝資産形成／老後関連で、時の塔＝近い／使用時期不明のとき）**：

> 【時間の門：先に使う予定は？】
> ムダギリくん「未来のために準備する前に、近いうちに使いたいお金もあるかな？」

| code | 選択肢 | 第一手と根拠の変更 | 面談の価値 |
|---|---|---|---|
| \`plannedExpense\` | 「1〜3年以内に大きな支払いの予定がある」 | 予定の支払いを優先して**金額と時期を調べる**。近い資金は長期準備と一緒くたにしない | 使う資金を確保した上で、長期の準備を比較 |
| \`noPlannedExpense\` | 「今のところ大きな予定はない」 | **生活維持のため手元に残す条件を確認**。近い使途がないこと≠投資余力あり | 家計・防衛資金・長期目標の条件 |
| \`uncertain\` | 「まだ分からない」 | **1〜3年に必要な支出の予定を一つ確認** | まずお金の使途と時期を整理 |

**原稿候補（架空ユーザー、\`plannedExpense\`）：**

> **未来の作戦書｜資産の道**
>
> **増やすお金を選ぶ前に、近く使うお金を守ろう。**
>
> 第2章では「資産形成」を目標に選んだ。今回は1〜3年という時期を選び、その間に大きな支払いも予定している。なら、その予定のお金と、もっと先のために残せるお金を同じものとして考えない方がいい。
>
> 第2章の見直し候補はまだ確定していない可能性があるから、**そのまま積立原資にはしない**。
>
> **今日の一手：** 予定している大きな支払いの時期と必要額を、分かる範囲で一件書く。
>
> **相談すると：** 近い支払いを守りながら、資産形成に使える条件があるか整理できる。
>
> **この作戦を相談する →**

**反証・NG**：
- \`noPlannedExpense\`でも「あなたには投資資金がある」と言わない。
- \`plannedExpense\`でも支出予定が少額かもしれない。投資一切不可と決めない。
- 目標を1〜3年で叶えたいことと、**実際の資金の使途/流動性**は同義ではない。
- \`cUpper\`・\`confirmedA\`は金額が表示されても運用可能なキャッシュへ変換しない。確認済み改善機会も実行済みかは別。
- 第2章未連携なら資金状況は不明のまま。商品推奨・具体利回り・NISA等への一律誘導を結果に入れない。
- 10年以上の長期目標でも、生活防衛/負債などが未確認なら株式や投資信託が適合すると断定しない。

**判定：改善候補（まだ100点ではない）**。本人の資金使用予定という新情報で、最初の行動が変わる点はDraft 0.7より強くなった。一方、資金余力の数値を導いておらず商品比較もできないので「資産形成診断で商品が分かる」などと説明してはならない。

## 4. 自然なRPG導線と「答えを聞く」ことの差

### 体験の意味と操作を一致させる
1. **第2章のギルド門から出発**：JOBと「守った/確認が必要な戦果」が映る。確認済み改善Aを貯金が増えた金貨として描かない。
2. **願いの旗**：第2章の目的地が確認できればそのまま利用。無い場合に選ぶ。旗が地図に立つ。
3. **時の塔**：叶えたい時期を選ぶ。時間軸により地図のルートが遠近変化する。
4. **霧の関門（**必要な場合だけ**）**：稼ぐ→現実にある手掛かり、資産形成→近く使う予定。選択によって霧が晴れる場所と最初の行動が変わる。**その他の結果で必要な質問がなければ、回答を求めず先へ進む**。
5. **未来の作戦書**：本人の正本JOB、今回の旗・時間軸、家計の「守る/確かめる」要素が一つの地図になる。画面は結論→理由→一歩→任意CTA、詳細はスクロール下へ。
6. **任意共有**：JOB画像と「未来の旗と時間の旅路」。資産額/目標期限の詳細/障害・相談理由を外部へデフォルト送信しない。**未回答なら演出・地図も虚偽の完成済みにしない**。

### 第1章→第2章→第3章の継続性
- 第1章：お金に関する本人の**判断傾向**。これを昇給/投資適性の証拠に変換しない。
- 第2章：現状の家計の**確定/未確定/守る価値**。数値の意味論はFROZEN。
- 第3章：本人の**希望と時期、現実的な制約と次の行動**。「今の満足 vs 将来の備え」「今守る資金 vs 長期準備」の両立や手順を見つける。
- 面談CV：**全結果から共通の「面談予約」**。内容は収入・資産形成・家計・住まい・教育等と本人が編集できる。事業が対応できない相談を約束しない。

### 行動経済学上の反論
同じE3設問を全員に見せず、**条件付き1問で収束する**方が回答疲れは減るはず。しかし少ない回答数で100点になる保証はない。E3がなくても納得できる結果、E3が無いと薄い結果を**Cognitive Pilotで比較**する。

### 人間味を出す文章ルール
- 強い断定や評価語「さすが」「あなたなら絶対」「正しい選択」より、**本人の目的と事実をつなぐ伴走口調**。
- セリフは原則1〜2文。吹き出しで長い専門用語を説明しない。
- リザルト上部の一文は3秒で意味が伝わる日常日本語にする。
- 強すぎる不安訴求でLINEを押させない。面談をしなくても今日の一手が残る。

## 5. 「100点を目指す」検証計画と計測契約

### ファネルKPI（リリース後に計測するもの）
**分母を揃えること**：第2章完了者（C2 complete）→C3任意開始率→C3結果到達率→CTAタップ→LINE/予約画面到達→日程確定→実面談。第2章からの直接面談も同じ母数で追跡。  
**重要**：LINE友だち追加やCTAクリックを「面談獲得」扱いにしない。予約済み＝**日時確定が確認できた件数**、実面談は別。

### 定性Pilot：8人（探索的で統計的有意性なし）
- 条件：C1/C2結果がある人/未連携の人、目標が明確/未定、仕事・育てる等を含める。実際の年収・借金・家族情報の共有を強制しない。
- ①「どこで新しい発見をした？」を自由回答し、**言われたことを繰り返すだけなら不合格**。
- ②「なぜこの一手？」を自分の言葉で説明してもらう。根拠を正しく理解しているか（本人申告 vs 公的統計 vs 第2章A/C）。
- ③「この選択肢はどちらでもいい？」と感じた設問／迷った設問を観察。
- ④「面談では何を解決できると思った？」を聞き、提供範囲との一致を確認。
- ⑤「友達に見せたい？」を聞き、**実際の共有意思**と、公開してよい内容を確認。
- 初期採択の目安：8人中6人以上が根拠を説明可能、5人以上が具体的な新しい気づきを述べ、6人以上が面談テーマを正しく理解。**少数サンプルの足切り目安であり製品品質の証明ではない**。
- E3を付けたことで離脱/操作ストレスが増えたのに発見が改善しなければE3削除。
