# ムダギリ診断 第3章 V1.6 イベント主導型RPG画面監査
更新: 2026-10-20 / 対象: public/pilot/chapter3-v16/ のみ

## 判断
従来のQ画面は、アニメーション付きの背景と小さな紋章があっても、本文→説明→7枚の縦長選択肢が主役のため「装飾された質問フォーム」に見えていた。第1章のJOB獲得・第2章の家計バトルの直後に配置すると冒険感が急に低下する。

**再設計の原則は「質問から物語を始めない。まず遭遇し、イベントの中で選ぶ」。**

## 画面の順序（原則844px級1画面）
1. 冒険の位置（第1〜第3章レール／進行スロット）。
2. 探索地点（既存ギルド／次の大陸の背景、130px級のランドマーク、公式ムダギリくん、発光・霧・地形のCSS、実況のセリフ）。
3. COMMAND：その場で進む道を選ぶ。ボタンは2列のゲームコマンドとして配置。選択肢の意味と回答キーは変更しない。
4. 戻る。基本はスクロールしないが短い画面・大きい文字では操作可能性を最優先しスクロールへフォールバック。

## 5つの遭遇イベント
| 画面 | イベント | 画面の動機 | 実際に知りたい回答 |
|---|---|---|---|
| 1 | 灯火の分かれ道 | 複数の未来を発見 | 叶えたい暮らし |
| 2 | 時の時計塔 | 時によって道が変わる | 期限 |
| 3 | 現在地の石碑 | 旅の記録を確認 | 準備状況 |
| 4 | 霧の番人 | 不透明な障害に遭遇 | 気がかり（なし・回答しないも正解） |
| 5 | 守護の祭壇 | 最後の守りたいものを選ぶ | 優先価値 |

## 視覚QA
- 探索シーンはヘッダーではなく主役。7行のアンケートリストよりも大きな場面として見せること。
- 320〜430px、844px高でイントロと5問が画面に収まる。低い画面600/667pxでは最下段が操作可能なこと。
- ランドマークは質問名と一対一に異なる。第4問は霧の番人に見え、第5問は守護の祭壇に見える。文字を読まなくても変化に気づくこと。
- 第2章のキャラクター画像を勝手に別の意味の「障害」として使わない。人物を暗い敵として描写しない。
- 新しい大きな画像を追加する前に、世界観の共通仕様・見かけサイズ・背景透明度・アセットの権利を確認する。

## 行動経済学・心理学・マーケティング・バズ理論
- 行動経済学：いきなり7択を見せず、先にシーンで状況を理解させる。タップの選択自由と戻る導線は維持。
- 心理学：「困りごと」が敵というより曖昧さ・霧の象徴。回答への強制・不安の煽りを避ける。
- マーケティング：次に進みたい気持ちと自己認識を蓄積し、結果の地図獲得→相談で何が分かるかへ一貫させる。
- バズ理論：物語の転換点（霧の番人・地図片）にシェアしたくなる強い場面を作る。ただし悩みや金額は共有しない。
