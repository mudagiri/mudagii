# 第3章 V1.7｜発見クエスト実画面・限定実験

更新：2026-10-11／**デモのみ・未FROZEN・現実の家計データ非接続**

## V1.6から何を変えたか

旧版は「望む未来を聞く→本人の回答を言い換える」ため、UIが動いてもプロダクト価値はFAILだった。V1.7では、`Chapter3AhaLab.tsx` をリザルトの主役として配置し、まず次の2つだけを深掘りする。

1. **旅行（実際に旅行を選んだ場合のみ）**：回数・1回予算→年間・月間準備目安→第2章の**未確定**候補と条件付き比較。回数を増やした場合の変化も表示。未確定候補は本人が削減済みとは表示しない。
2. **資産形成で「仕事を減らしたい」を明示した場合のみ**：現在年齢・働き方変更年齢・比較終了年齢・手取り収入差・任意の積立額→収入差の単純累計と積立拠出元本を**別物として**表示。収入差を月5万円小さく変えた場合も比較。**2つを差し引いて資金不足・投資適性を断定しない**。

旅行目標でも「趣味のみ」を選んだ人に「旅行の回数」を聞かない。他6目的地やまだ具体的な希望のない人は、現段階でこの新しい発見を達成していると主張しない。

## デモの検証方法

- 入口：`/pilot/chapter3-v16/chapter3-pilot.html`
- 第2章デモ目的地に「旅行・趣味」か「資産形成」を選ぶ。
- **通常の4画面**で答えてリザルトを見る。または、明示的に「発見ケースをすぐ試す」を使って**架空の回答**で一気に結果へ行く（本番導線ではない）。
- 結果の「仮の数字を入れて体験する」で、AHA比較の条件をセットする。これは**本人のデータではない**。
- 旅行なら年2回→年3回、働き方なら収入差を月5万円変えるボタンで比較する。
- 数字を自分で入力して変えられるがデモでは保存・送信しない。結果への共有同意もデモのみ。金融相談予約には接続しない。

## 絶対に変えないもの

- 第1章のJOBとSTYLEは再判定しない。JOBが投資適性・リスク耐性を決めることもない。
- 第2章の確定改善額 `confirmedA` と未確定見直し候補 `cUpper` を足さない。候補が全部改善された場合はあくまで「仮に」という反実仮想。
- 第2章の「守る」支出を勝手に斬らない。
- 数字による結果は「本人が入力した条件に基づく単純計算」とし、資金不足・金融商品リターン・達成可能性と偽らない。
- 第2章直接相談・LINE・本番GASやFROZENコアは未変更。診断結果を受け取るのに面談は不要。
- 旧版の「世界観」と新AHA結果は両方存在するが、価値を測るのは後者。装飾のQAと新しい気づきのQAを混同しない。

## 5視点の未達ゲート

| 視点 | 現時点 | 次の合格条件 |
|---|---|---|
| 行動経済学 | 入力数値を変更して影響を見る操作 | 一律4問+追加5数値欄ではUXが重い可能性。目的別の最短質問へ設計し直す |
| 心理学 | 金額の前提を明示し、怖がらせない | 実ユーザーが自分の言葉で新しい発見を説明できるか |
| マーケティング | 本人の疑問が「いくら積立するか」から「働き方を変える条件」へ具体化する仮説 | 有効な実面談（直予約との比較）、納得度を実測 |
| バズ | 既存JOBとクリア画面を維持 | 私的な金額をシェアせず、自由に共有したくなるか |
| 第1〜3章 / RPG | 同じJOB・ギルド・戦果とムダギリくん | 本物のC2goal/守る支出・金額をデータ契約で引き継ぎ、再質問しない |

**今のV1.7は2ケースの価値仮説を動く画面にした段階。まだ「100点」「全目的地完成」「新しい発見が検証済み」とは言わない。**
