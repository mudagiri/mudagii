## ユーザーからの再指摘と決定
「比較が複数あります」と説明すること自体が複雑。画面では`あなたの支出 → 比較目安1つまたは判断ポイント → 次の一歩`を主線にする。

1. 2024年の年齢×世帯区分×年収帯の公式参考率を直接使える食費・光熱費・日用品は、その参考率を主表示する（世帯主/勤労者/n>=50のゲート維持）。費目範囲の相違は任意の根拠に説明。
2. 公式の同条件率が採れないカテゴリでは、採用済みの参考目安がある場合にのみ1つ表示。別統計の関連費目率は並べない。適切な参考額がない場合は利用状況・契約内容の判断ポイントを表示。
3. 2024年の関連公表費目、2025年の年収だけの参考、別条件の参考、数値の出典等は、各カテゴリの閉じた`出典・統計の補足を見る（任意）`内に集約。データは削除せず、初期画面で競わせない。
4. サブスク等、数字で比較できないカテゴリの実際の判断理由を開閉欄に巻き込まない。説明は主表示に残す。
5. 公式の数値を削減可能額や未確定上限に変換しない。FROZEN engine、確定改善額、参考上限、GAS、LINE、共有カード、第1章・第3章、本番rootアプリコードは不変。
