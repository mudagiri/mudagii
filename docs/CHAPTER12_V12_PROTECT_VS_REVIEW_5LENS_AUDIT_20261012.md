# ムダギリ診断｜第1章×第2章 答え合わせ V1.2・5視点監査（2026-10-12）

**位置づけ：隔離Pilot／Draft PR #46／未FROZEN／本番リザルト通常表示は変更しない。**

## なぜ改修したか

V1.1には「楽しさ重視→娯楽費が守る→月24,000円（年288,000円）」という本人入力の単純な再掲が中心だった。その状態では、性格とお金の使い方がどう違うのかを考える材料が弱く、ライフプラン面談を自然に考えたくなる保証もない。390pxの画面でカードが約575pxあり、本来の戦果報告までの距離も長い。

**V1.2の仮説：価値観と家計の数字を並べるだけではなく、同じ人の「守りたい支出」と「確認済み見直し機会」を区別して可視化すると、まず何を確認するか考えやすい。** それでも性格の的中率・投資適性・節約実行は証明できない。

## 変更した体験（仮想デモの一例）

- 第1章：楽しさ重視（ENJOY。第1章の3軸の正誤は推定しない）
- 第2章：娯楽・趣味／本人が満足して「守る」／月24,000円
- 第2章：未使用・解約可能と本人が確認したサブスク／確認済みの**改善機会**／月1,200円
- **同じ画面に2枚だけ**：「🛡 守りたい娯楽・趣味 24,000円/月」「🔎 未使用サブスクの確認済み改善機会 1,200円/月」。
- ムダギリくん：「君が守りたい楽しみと、見直せる契約は別物だぞ！」
- 次の一手：「娯楽費はそのままに、未使用サブスクの解約条件を先に確認する」
- このカード内で**差額／合計／投資原資は計算しない**。右の1,200円は本人申告に基づく解約前の改善機会であり、まだ現金を確保できていない。
- 根拠は折りたたみ。SNSには金額・家族・診断ID・価値観との突合せを自動転載しない。

## ルールによる発火条件

実装：`scripts/chapter12-answercheck-experiment-v1.mjs` の `protectedVsReview`

1. 第1章の正規引継ぎ契約、匿名ユーザーID一致、セッションID・診断IDあり。
2. 第2章の正規12カテゴリが揃い、重複・不正ステータスなし。
3. 本人の代表STYLEがENJOYで、娯楽費が実額あり、本人満足（satisfied / verySatisfied）かつ`v5Status=protect`。
4. 別カテゴリのサブスクが既知、`v5Status=cut`、未使用・解約可能と本人回答で確認。
5. `0 < aAmount <= subUnusedAmount <= sub.amount`。3値は有限・安全な整数で、表示額が記述支出/確認済み改善機会から逸脱しない。
6. 上記を満たさなければ2枚比較**なし**。これまでの単独価値観ヒントはそのまま。SECURE×保険など架空の整合判定は追加しない。

現時点で2枚比較を出せるのはENJOYのこの組合せだけ。他STYLEへ証拠のない「守るvs見直す」をコピーしない。多くの人が対象外でも、無理に一致を生成しない。改善機会の定義はV5/FROZENのまま。

## 5視点レビュー（定性仮説）

| 観点 | 前より改善した点 | まだ不合格の可能性 |
|---|---|---|
| 行動経済学 | 1画面で守る選択と確認行動を分離。年換算でむやみに大きく見せない | 2枚を比較したからといって右を実現可能なお金と勘違いするかもしれない |
| 心理学 | 楽しい支出を「ムダ認定」せず、本人の満足と未使用契約の事実を尊重 | 他の人は証拠不足で結果が薄い。タイプの正解率と勘違いしないか |
| マーケティング | 「全部削る」ではない個別の次の一歩を渡す | 今回の1,200円の確認だけでは面談の十分な理由にならない |
| バズ | シェアは第1章JOBカード。家計数字・家族・組合せは非公開 | 第2章の有機的拡散は未検証 |
| RPG | 第1章の公式JOB、第2章「盾」と見直し対象、ムダギリくんの会話が意味を持つ | カードの見た目だけでなく宝箱・戦果報告との距離が短い必要 |

## 完了確認ゲート

- エンジンの安全チェックを64→84へ増強（ID、12カテゴリ、0円、不正金額、未確認解約、見直しを合算しない等）。
