# MONEY TYPE CARD VISUAL SYSTEM V1

Status: DESIGN SOURCE OF TRUTH
Scope: Money Personality / Chapter 1 result card, SHARE preview, exported SHARE PNG
Applies to: 8 JOB × 4 STYLE = 32 TYPE

## 0. Core principle

The card must read as a premium collectible trading card first, not as a SaaS panel, poster, wallpaper, or rainbow sticker.

Visual hierarchy:
1. JOB-colored premium card stock
2. JOB-specific world motif
3. Character
4. Metallic frame
5. Sparse holographic foil reflection
6. TYPE information

Hologram is a surface treatment, never the base background pattern.

## 1. Shared rules for all 32 types

- Keep the center materially calm and readable.
- Concentrate holographic facets around corners / outer perimeter and occasional isolated reflections.
- Never repeat large geometric triangles at equal intervals.
- Never paint the whole card in rainbow gradients.
- Character is the visual hero.
- TYPE code and CARD ACQUIRED are secondary.
- Frame should feel metallic / etched, not neon.
- Result card, in-page SHARE preview, and exported SHARE PNG must use the same material system.
- Still screenshots must already feel rare; motion only adds a subtle glint.
- JOB defines the main visual identity.
- STYLE only adds a secondary accent; STYLE must not overwrite the JOB color.

## 4. STYLE accent system

STYLE modifies small accents only.

- DRIVE / 前進: #ff625f
  Use on micro badge edge, tiny spark, secondary glint.
  Impression: momentum / push.

- ENJOY / 満足: #ff86c8
  Use very sparingly. It must never wash the card pink.
  Impression: pleasure / emotional reward.

- SECURE / 安心: #62d9e8
  Use on secondary reflection or fine line.
  Impression: calm / protected.

- OPTIMIZE / ムダなし: #7bdc91
  Use on tiny efficiency cue / reflection.
  Impression: clean / controlled.

STYLE contribution target:
- JOB visual identity: ~85%
- STYLE visual nuance: ~15%

## 5. Hologram material rule

Approved direction:
- Fine / irregular diamond-prism fragments
- Stronger near corners and edges
- Sparse isolated facets inside
- Bronze / JOB-colored stock remains visible
- One narrow moving glint is allowed
- Static screenshot must not look flat

Rejected:
- full rainbow field
- repeating triangle wallpaper
- evenly-spaced large shards
- large radial rainbow bands
- sticker-like hologram texture

## 6. Parity rule

The following three outputs must look like the same collectible:
1. Result TYPE card
2. 08 / SHARE preview
3. Exported SHARE PNG

Allowed differences:
- SHARE PNG may use slightly larger character and simpler spacing for social readability.
- Long explanatory copy may be removed.

Not allowed:
- Different card stock color
- Different hologram style
- Different JOB motif
- Different frame language
- Giant TYPE code only in SHARE

## 7. Real-device acceptance checklist

PASS only if all are true:
- At first glance the JOB is visually distinct from the other 7 JOBs.
- Character is the first focal point.
- JOB motif is recognizable behind the character.
- Holo reads as a material reflection, not a wallpaper.
- Card base color remains visible.
- Text is readable without fighting the foil.
- Result and SHARE feel like the same card family.
- Screenshot alone feels collectible / premium.
- No visible SaaS-panel feeling.
- No full-rainbow sticker feeling.

## 8. Frozen design decision

戦術ハンター is the current calibration sample only.
Its bronze/web/reticle treatment must NOT be copied literally to the other 7 JOBs.
What is shared is the material system and composition; what changes is the JOB color, motif, and atmosphere.
