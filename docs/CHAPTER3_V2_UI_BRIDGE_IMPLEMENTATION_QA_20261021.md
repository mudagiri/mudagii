## 1. 使い方と隔離条件

新UIは以下の両方が必要：
1. 第2章のV3.2表示（\`chapter2v32=1\` または専用ビルド環境 \`VITE_CHAPTER2_V32=1\`）
2. 第3章V2の明示フラグ（\`chapter3v2=1\` または隔離ビルド環境 \`VITE_CHAPTER3_V2=1\`）

ただし、**これは完成した第2章結果を表示できるセッションでの起動条件であり、公開URLやその到達可否を保証するものではない**。CIではGASを無効化して\`dist/\`アーティファクトを作るだけで、GitHub PagesやVercelへ公開していない。

本番mainの結果画面にはこのフラグ版を投入しない。既存の第2章直接CVを残す。
