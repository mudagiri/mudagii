# ムダギリ診断 第3章｜未来を変えるクエスト 詳細設計 V1.1
更新：2026-10-17 / 状態：**DRAFT（未FROZEN・未公開）**
対象：第1章お金の性格診断 → 第2章家計クエスト → 任意の第3章 → 学習・総合相談・希望領域別情報提供

## 0. 結論と、以前の試作品からの変更
第3章は「投資商品を判定するコンテンツ」でも「紹介先を全部並べた広告ページ」でもない。本人の目的・時期・現在の行動・関心から、**なぜ次に何を確認するとよいか**を一つ説明し、興味を持った領域の学習や相談へ任意で進める。
テーマは **お金の力（現在使える元本）・時間の力（積立/保有期間）・信用力の活用（借入の仕組み）＋稼ぐ力（本業/転職/副業/学習）**。これは理解のための分類であり、4つ全部使うことや借入することは成功条件ではない。

重要な既往監査：旧PR #45（CHAPTER3_PRODUCT_CONCEPT_SELECTION_GATE_20261012.md）は、旧V1.6〜V2.1で「質問を増やしたのに、新しい関係・驚き・具体的な意思決定を返せない」と判定。今回も第3章の独立性は実測前に確定しない。**第2章→直接相談 / ここで終了 / 第3章へ任意進行**を残したままA/Bテストで判断する。旧PRをコピーした新バージョンではない。

## 1. 出口から逆算した提供価値
開始前の期待：「今あるお金、これからの時間、仕事や副収入、借入という方法。それぞれを使う前に、**自分が次に確かめること**が分かる（約1分）。」
実際に返すもの：
1. 前章で確定した8JOBキャラクターと4STYLEに続く「未来の作戦書」。
2. 3つの力を **活用中・関心あり・今は選んでいない・未確認** の事実状態で表示。強さの点数化はしない。
3. 本人が回答した目標・期間・困りごとを組み合わせた **具体的な「次の確認質問」1つ＋なぜそれが必要か＋今日の小さな一歩**。
4. 関心を示した領域だけの一般的な学習・総合相談・適法な紹介先閲覧。
5. 面談に進まなくても結果を保存・共有せず終了できる。

不採用：見せかけの適性スコア、信用力の高さ判定、融資可能額、投資予想利回り、年収/性格だけでの金融商品推薦、恐怖訴求・ローン礼賛・高額報酬を理由にした紹介順位。

## 3. 実際の設問文・選択肢（採用候補コピー）
### Q1 未来の目的
見出し「これから、お金の面で叶えたいことは？」
副文「いちばん近いものを1つ。まだ決まっていなくても大丈夫。」
- `stability` 毎日の暮らしに、もっと余裕がほしい
- `future` 将来のお金の心配を減らしたい
- `retirement` 老後の暮らしに備えたい
- `family` 家や子どものことに備えたい
- `freedom` 好きなことを選べる余裕がほしい
- `undecided` まだ決めていない

※ 家や子どもがいないことを前提にしない。自由記述はV1.1では要求しない。

### Q2 時間軸
見出し「それ、いつ頃までに叶えたい？」
- `under3` 3年以内
- `threeTo10` 3〜10年くらい
- `over10` 10年以上先
- `unknown` まだ分からない
※ 短期=投資不適、長期=投資適と自動推定しない。

### Q3 3つの力の今
導入「次は、今の自分を見てみよう。全部使っている必要はないよ。」
カード1「まとまったお金を運用してる？」（お金の力 / `capital`）
カード2「積立や長期の運用をしてる？」（時間の力 / `time`）
カード3「借入を使う投資や事業の方法を知ってる？」（信用力の活用 / `credit`）
各カードの状態キー：`active` / `interested` / `notNow` / `unknown`
- お金・時間： 「今やっている / 興味はある / 今は考えていない / よく分からない・答えない」
- 信用力： 「使ったことがある / 仕組みを知りたい / 利用するつもりはない / よく分からない・答えない」
**信用力カードは実際の与信力を測っていない。** ユーザーには「借入できるかの判定ではありません」を直下に常設。状態の呼び名は「借入活用への経験・関心」。利用しない選択に減点や鍵演出をしない。

### Q4 今の気がかり
見出し「今、お金のことで一番気になるのは？」
- `living` 毎月の生活費に余裕がない
- `debt` ローンや返済の負担が気になる
- `dontKnow` 何から始めたらいいか分からない
- `loss` 損をするのが不安
- `busy` 忙しくて考える時間がない
- `none` 特に困っていない
- `skip` 答えたくない
※ 一つだけ選択。これは医療・負債・投資適性の確定診断ではなく本人の自己申告。

### Q5 次に知りたいこと
見出し「次は、どんな選択肢を知ってみたい？」
副文「気になるものを2つまで。見るだけでもOK。」
- `investBasics` 資産運用の基本
- `propertyLearning` 不動産投資・借入の仕組み
- `sideWork` 副業で収入を増やす
- `career` 転職・年収アップ
- `skills` 今の仕事に役立つスキル
- `insurance` 保険・保障の見直し
- `budget` 毎月の家計改善
- `consult` 自分の場合を相談したい
- `resultOnly` 今は結果だけ見たい
`resultOnly` は排他的。重複選択や3つ以上選択は受付不可。
他領域を選んでも、実際の商談・紹介は別画面で本人が希望し、必要な手続・同意が成立した場合に限る。

## 4. 決定的判定テーブル（同時一致は上が優先）
| 優先 | 条件 | storyKey | ユーザーに渡す新しい問い |
|---|---|---|---|
| P0 | Q4=生活費/返済 | household | 返済・生活費を続けた上での毎月の余力は？ |
| P1 | 3年以内 & 元本/積立運用中 | short_active | 3年以内に使う資金は運用中のお金と分けてある？ |
| P2 | 3年以内 | short | 必要になるお金はいつ・何のため？ |
| P3 | 目的/期間が未定 | no_goal | 近い将来使う予定のあるお金は？ |
| P4 | 副業/転職/学習に関心 | earning | 新たな収入のために使える時間・譲れない条件は？ |
| P5 | 元本/積立運用中 | existing | 今の方法は目的と使う時期が合っている？ |
| P6 | 不動産・融資に関心 | borrowing | 借入のコスト・価格下落・返済継続を比べた？ |
| P7 | その他 | start | 目的・元本・時間・リスクのどれを比較する？ |

問いを返すこと自体が目的ではない。**前に答えた情報2点以上の関係**から、本人がまだ答えていない判断条件を1個提示する。例：Q2「3年以内」×Q3「積立運用中」→値下がり時も必要な生活資金が利用できるか。適合性・資金不足を断定しない。

## 5. リザルトの順番（iPhone 390pxを基準）
1. 「未来の作戦書を獲得！」＋第1章の既存JOB・ムダギリくん
2. **一番伝える発見：次に確かめたい問い1個**（タイトル/理由/具体行動）。金融商品の広告をファーストビューの主役にしない。
3. 第2章の「確認された改善額」と「未確定候補」を別々に表示（データ無し・確認不可は表示しない）。改善額＝現金確保済みとは限らない。
4. 3つの力の状態カード（信用力の判定ではない注意表示付き）。
5. 自分で選んだ次の情報・相談へのメインCTA（1個）＋補助導線。
6. 詳細図鑑（3つの力・稼ぐ力を比較、メリットだけでなくリスク・手間・前提を示す）、保存/共有。

共有カードはJOBと非金融的な「未来クエストを始めた」程度。目標・信用力・収入・家計金額・返済・選んだ副業等を勝手に共有しない。

## 6. 分野別導線と法務境界
- `investBasics`：金融知識の一般的解説。個別商品は別途法務審査を通すまで推奨/自動マッチング禁止。
- `propertyLearning`：借入のコスト・返済・空室・価格下落の一般情報。借入能力の高低を表示しない。
- `sideWork`：副業の選択肢/業務委託/雇用の違いをまず確認する。
- `career`：キャリア情報。AIによる選別・雇用のあっせん等の実態に応じ職業紹介/募集情報等提供の該当を審査。
- `skills`：条件/費用が明確な講座情報を紹介。
- `insurance`：保障見直しの学習から開始し、既存の第2章保障専用LINEを無条件に差し替えない。
- `budget`：第2章のアクションへ戻る。
- `consult`：何を相談できるか、予約後に何を得られるかを明示。面談予約確定とLINEクリックを混同しない。
- `resultOnly`：無料結果を受け取って完結。

紹介先データの最小列：offerId, category, providerLegalName, description, eligibility, feesAndRisk, compensationDisclosure, legalReviewStatus, consentVersion, status。**review未完了・停止中・法的な行為の範囲が未確認の案件は非公開。**
紹介実行の成立条件：本人の明示的希望 → 提携先・目的・送る情報の提示 → 有効な同意 → API/バックエンドで処理 → 送信結果と提供記録の保存。結果表示段階での一括自動送客は禁止。
当社に登録/許認可がない場合の金融・人材関連の許容範囲は、商品と取引類型別に法律専門家による確認を要する。

## 7. 既存章との連携・信頼境界
- C1は正しい本人セッションとの整合と検証済み状態を持つ場合だけJOB/STYLEの演出を継承。JOB/STYLEで商品適合性・融資可否・年収を推定しない。
- C2は正本に基づく認証・整合の通ったデータだけ参照。未確認の場合はC2未連携扱いとし、架空金額を表示しない。
- C2のconfirmedSavingMonthlyJPYとreviewCandidateUpperMonthlyJPYを加算しない。前者もまだ実行していない場合がある。元本や積立可能額に変換しない。
- 同一匿名IDだけで本人認証済みとはみなさない。製品実装では既存の信頼境界に適合する正規アダプターを設計すること。
- C1/C2のFROZEN採点・12カテゴリ・比較・GAS/Sheet・旧本番・既存LINE導線は変更しない。
- フロントエンドのパラメータ入力は信用しない。送客時の同意・契約前確認は別のサーバー側で検証する。

## 8. 4視点＋RPG の合格条件
| 視点 | 本質的な検査 |
|---|---|
| 行動経済学 | 「次に何が得られるか」が入口10秒で分かり、5画面の追加負担に見合うか |
| 心理学 | 未利用を敗北扱いしない、弱点を捏造しない、相談せず完了できる |
| マーケティング | 本人の問いに対して情報/相談の価値が具体的、直接面談と競合していない |
| バズ | 第1章SSRで流入を獲得し、第3章の金融情報を共有させない |
| RPG | C1冒険者→C2の戦果→C3未来作戦書。同じキャラ、ポーズ、公式ギルド演出、読みやすい吹き出し |

## 10. Ver.1.1をFROZENしない条件
- 入口の価値を本人が自分の言葉で説明できない
