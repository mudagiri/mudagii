# 第2章「当たってる感」V1｜4視点監査と認知テスト設計
更新：2026-10-14。対象：Draft PR #46。**実ユーザーで未検証。公開判定ではない。**

## 目的と非目的
第1章の「自分の価値観が言語化された」と第2章の「回答を読んだうえで家計の守る支出と確認先を示してくれた」をつなぐ。
目指す反応は「ちゃんと自分の家計を理解してくれている」「この指摘なら確かめたい」。
「当たってる」はUXの共感・納得を指し、**性格の統計的的中率・実測削減・節約実績・金融商品の適合判定ではない**。
本人が入力した内容の言い換えだけで全員に「的中！」と表示しない。第1章JOB/STYLEから収入・投資適性・無駄遣いを推定しない。

## 実装：一つの既存セリフを根拠に合わせて変更
- `chapter2-recognition-v1.ts` はV5 result rowsから**明示的な本人回答**だけを抽出。元データは変更しない。
- 12カテゴリ揃っていることを確認。重複・欠け・NA・unknown・ゼロ金額では本人らしさを捏造しない。
- 守る根拠：娯楽/食/美容への「満足」、自己投資の「目的/成果」、住まいの「守る/妥当」。該当カテゴリは`v5Status='protect'`かつknown=true・正の支出が必須。
- 見直し根拠：V5で`cUpper>0`の項目は**未確定候補**としてのみ言及。未使用サブスクは`subUnusedAmount>0`かつ`subCancellationConfirmed=true`かつ`aAmount<=unused<=amount`を要求。
- 優先順位：①本人の守る支出＋未使用/解約可能なサブスク、②守る支出＋未確定見直し候補、③守る支出のみ、④確認済みの未使用サブスクのみ。証拠なしなら`null`として既存の非断定セリフを維持。
- `ResultScreenChapter2V32.tsx` は**戦果報告後の既存ムダギリくん1セリフだけ**を差し替える。追加カード・追加質問・診断コア・金額・CTA・GAS・SNS共有内容は変更しない。
- 本文に正確な金額や世帯属性を直接含めず、個人情報はシェアカードに含めない（`shareAllowed:false`）。根拠コードのみ返す。
- 第1章×第2章の任意「答え合わせ」試験カードは別機能で、本人のSTYLEと家計カテゴリを**同一人物回答の照合**として表示。相関の証明とは呼ばない。
- 最終統計データ契約とFROZEN実装の所得補正P0衝突は、別ゲートでマージ保留を継続。

## 行動経済学／心理学／マーケティング／バズ理論：各25点の監査ゲート
現時点で点数は**未確定**（実ユーザーの測定なし）。

| 視点 | 25点満点の要件 | 失格となる表示 |
|---|---|---|
| 行動経済学 | 一番大事な支出を守る理由→別の確認先→小さな一手が自然な順番。余計なタップや選択肢を増やさない | 平均値との差を「あなたのムダ」として高く見せる／大きな将来額から相談を誘導 |
| 心理学 | 本人が答えた根拠を明示し、満足する出費を尊重。非該当なら無理に当たったことにしない。自律性を守る | バーナム的な万能褒め言葉、タイプによる浪費決めつけ、恥・老後不安の煽り |
| マーケティング | 「なぜ？」→「次に何を確認？」で自然に相談へつなぐ。保障相談は別導線、予約済みとは言わない | 保障の不足・古い医療保険が無意味・加入が必須などの断定 |
| バズ | RPG・JOB・ムダギリくんを連続させる。共有には本人の秘密・支出・保険・家族情報を含めない | 共感文・家計金額・相談コードを本人の操作なくSNSに出す |

## 認知テスト：5〜8人、誘導しない
1. 第1章から第2章まで本人の通常回答で通してもらう。画面・フォント・タップ・戻る動線を実機観察。研究対象者の特定情報や実支出はテストメモに残さない。
2. 第2章リザルト表示後、**まず自由回答**：「この画面で一番印象に残ったことは？」「自分の生活に当てはまると感じた箇所と、違和感のある箇所は？」。「当たったよね？」は聞かない。
3. 次に理解確認：「何が確定した改善機会で、何が未確定候補？」「この結果は何を根拠にあなたに当てはめたと思う？」。「第1章のSTYLEは実際の行動の証拠になったと思うか？」と誤読を確認。
4. 最後に実行意向：「今やるなら何を最初に確認する？」「家計や将来について相談したいと思った？その理由は？」。個人情報を告げる必要はない。
5. 観測する結果：①具体的な本人回答を根拠として挙げた割合、②自然な「自分ごと」の発言件数、③確定/未確定の誤認数、④相談・保障・共有の導線理解、⑤スクロール・小文字・誤タップ・復帰。**N=5〜8の割合を統計的妥当性・的中率と呼ばない。**
6. 反例：反応が薄い・違和感が強い・バーナム的な褒めと感じたら、無理にコピーを強くせず具体的な根拠やUI上の位置を修正する。
