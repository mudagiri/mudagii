# 第2章｜2024年公式原本 12カテゴリ関連費目の実測値再接続 — 2026-10-21

## 結論
公式原本から**食費・光熱水道・日用品（限定範囲）に加え、通信・自動車・娯楽交際・美容服飾・住居・保険・教育の7関連分類**の支出額を、**年齢×世帯区分×額面年間収入階級の同一公表セル**で再取得できた。計10カテゴリに関連統計の実測値が存在する。サブスクと自己投資の公式独立カテゴリは存在しない。

ただし「公式の関連項目が存在」≠「当プロダクトのカテゴリ別公式平均」≠「あなたの適正割合」≠「節約額」。スコープの相違を明示し、同世帯の参考率を公表原表から算出できる高額所得帯の**7関連カテゴリだけ**表示を第一段階として構築する。

## 実装したゲート
1. 年収1000万円以上の`1000plus`を自動的に1000/1250/1500万円区分に代入しない。既存の**任意の詳細額面年収選択**を再利用。
2. 二人以上の家計全体を診断する場合のみ。単身の高額所得は統計上のn不足のため表示不可。
3. 回答者年齢＝世帯主年齢の確認、世帯主が勤労者（給与所得者）の確認が両方済むまでは非表示。30代年収1500万円以上、70代年収1250万円以上等のn<50は表示不可。
4. 元コード `age-income-joint-high-2024-official-v1.ts` に格納した食費・光熱水道・可処分所得・標本数と追加7カテゴリの原本セルが一致するようQA。
5. 既存の原表3参考率は変更しない。追加の7カテゴリは**各カードに『公表費目の関連率（診断カテゴリの平均ではない）』と一体で併記**。現時点で本人支出との差額・差分パーセントポイント・見直し余地は算出しない。
6. `confirmedA`,`cUpper`、第1章・第3章、GAS、シェアカード、属性保存・LINEに新統計を流入させない。
7. 詳細画面を過度に長くしないため、既存の12体敵図鑑カードの既存デザインを継承し、数値は条件確認後だけ表示。Chromium/WebKit 320/390/430px 回帰QAを必須とする。

## 未解決の範囲・次工程
- 2024年の原本に同じ公表費目があっても、年収500～999万円や単身世帯すべてでn>=50・同じ世帯主年齢・就労条件が一致するとは限らない。新カテゴリの**中所得帯・単身の表示**は各区分ごとに追加監査が必要。
- 2024年統計の「二人以上」は3人・4人・5人が混在。2023住宅・土地統計の賃貸専用参考、生命保険文化センターの保障専用参考、車維持費の保有者調査、教育段階別基準とは**別レンズ**として扱う。
- 最終完成は12カテゴリすべての入力/参考/根拠/アクションを統合し、比較基準・推計の区分を目視・実機iPhone QAで審査してから。現時点では高所得関連費目の第一段階実装。
