# ムダギリ診断｜第2章リザルト V1.9 情報階層・RPG背景・余白のデザイン監査

日付：2026-10-13／対象：Draft PR #46 の隔離プレビュー。診断コア・正本データ・GAS API判定は変更しない。

## 指摘と根本原因
「背景がかなりシンプルな色なのに、ごちゃごちゃしている。ムダギリくんの世界観がちょこまか出てくる」。

UIの密度とRPGの世界観は別軸。既存画面は各セクションに金枠・発光・ラベル・カード背景が繰り返され、ヒーロー、宝箱、未来金額、JOB、敵、保障、面談、共有に同程度の注意を要求していた。特に同じ候補月額の再掲、5つの会話、12カテゴリ図鑑・8択の目標・複数の面談CTAが「戦果→理解→次の一手」を分断した。

## V1.9の3層情報設計
1. **主役（常時開示）**：QUEST CLEAR、月最大の未確定候補、全候補の金額・理由・確認行動、1/5/10年の仮定、4STYLEからの連続性、保障確認カード、ライフプラン相談。これらは詳細タップに隠さない。診断額は未確定であり、確定改善額を混ぜない。
2. **支え（やや落ち着いた表示）**：JOB・戦果数・確定改善額、節目でのみ話すムダギリくん。公式アートでギルドホール→戦利品→次の冒険をつなぎ、二次カードは低彩度・弱い枠にする。
3. **寄り道（本人が望むとき開示）**：12体の敵図鑑、行動の再確認、任意の8目標。全文は削除せずアクセシブルな `details/summary` に収納する。任意目標が未選択なら2つめの相談CTAは出さない。保障LINEは別目的の専用アクションとして保持。

「すべての情報を閉じる」は行わない。**未確定候補の内訳・根拠と保障理由は常時表示**という以前のUX合意を最優先する。
