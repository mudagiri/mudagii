# ムダギリ診断 第3章 V1.5｜実装コード監査と4視点リデザイン

更新日: 2026-10-17。**第3章だけ**を修正。第1章・第2章の既存ソース、FROZEN判定、基準Excel、GAS/LINEには変更なし。

## 結論
V1.4は物語としてつながるが、結果画面の情報設計とCTAの価値が弱い。具体的に、リザルトは①報酬→②地図3片→③前章継承→④ペイン・ゲイン→⑤結果の意味→⑥利点話法→⑦3つの力→⑧次クエスト→⑨シェアの縦積みで、最重要の本人の発見とCTAが深いスクロールの後だった。さらに「選んだ2つの選択肢を見る」が共通の一般論を開くだけだった。

V1.5は**「個人の発見→第一片の獲得→自分の一歩→任意のシェア→詳しい根拠」**に組み替えた。利点話法は捨てず、詳細を自発的に開いて読む人に見せる。CTAの先には選択した具体的領域ごとに意味のある次の確認クエストを置く。架空の差額、金融商品の推薦、融資可否判定、LINE誘導は引き続きなし。

## 第3章の4つの監査視点
| 視点 | V1.4での具体的な欠陥 | V1.5の修正 | 検証指標（未実測） |
|---|---|---|---|
| 行動経済学 | 重要な次行動が説明の最下部に埋まり、選択肢過多・情報過多 | 意味のある気づきを結果の先頭に配置し、同じページ内の次クエストへ1CTA。補足は折りたたむ | 次クエスト表示率、到達までのスクロール距離、離脱率 |
| 心理学 | 物語の達成直後に長い説明が始まる。Q4「不安なし」に「不安をつくって…」というメタ発言 | 先に本人の回答から導いた問い、具体的な生活価値。無理に不安を作らず自然な会話へ修正 | 「自分に関係ある」の自発発言、ハッとした具体箇所、反発感 |
| マーケティング | 「選んだ選択肢を見る」ボタンの先が汎用文。ボタンの約束を満たさない | 8領域について、特徴ではなく本人の判断便益→比較すべき3条件→小さな一歩→リスクをセットで提供 | 関心領域別ガイド閲覧率、次の具体アクションの言語化率、相談閲覧率 |
| バズ理論 | テキストシェアが汎用的。長い結果を読み切らないと到達できない | シェア動線を根拠より前に移動し、第一片獲得のストーリーと結びつける。回答金額・気がかりは非共有 | コピー率と実投稿率を分けて測る、シェア経由の第1章開始率 |

**判定上の注意**：この表は認知心理学や行動経済学の効果を実験で証明したものではない。スコアの断言を避ける。自動QAは表示と遷移の正しさを確認するだけ。これまでの営業研修・利点話法資料は、訪問者を脅す道具に使わない。

## UI構造 V1.5
1. 新エリアへの進入：第1章JOB、第2章戦果、未来の霧という物語を維持。
2. 5問：ゴール・時間・現在の手段・本人の気がかり・本人の興味。過度に商品へ誘導しない。
3. クリア報酬：未来の地図第一片。必要額と現在地のギャップは未解放。
4. **最初の重要情報**：回答の組合せから導いた本人への問い。深く読む前に次の一歩へ進める。
5. 地図の3片：①獲得、②必要額未確定、③現状との差未確定。
6. 選択された領域に応じた具体的な学習クエスト。相談は義務ではなく別ルート。
7. シェアは任意。プライバシーに触れる回答や金融額をSNS本文に含めない。
8. **詳しい根拠は折りたたみ**：第1・2章の記録、ペイン・ゲイン、利点話法の「だから→だから」、3つの力。

## 過大表示と反証ゲート
- 「確定改善額」「未確定候補」は実データがないので表示しない。平均との差を削減可能額とは呼ばない。
- 第3章単独デモでは前章のデータ引継ぎがない。サンプルの8 JOB画像は架空演出を本人がオンにしたときだけ。
- 8領域の説明で、予想年利・収入増・融資額・住宅購入の成功を保証しない。保険は公的保障・治療状況変化も確認対象とする。
- 返済や生活費の不安を本人が選んだ場合、運用・融資より家計の確認を先にする。
- ユーザーが「結果だけ」を希望したとき、強制送客しない。
- **ユーザーに反証してもらう基準**：「結果が長い／CTAが分かりにくい／自分向けの情報じゃない」のいずれかが見られれば構造修正。
- **実測を要求する基準**：5〜8名の非誘導インタビュー、3秒での第一印象、結果1画面に何が見えたか、具体的な次行動を自発的に答えられるか。最終KPIは相談の実施と顧客の納得度。第2章直相談とのA/Bが必要。
