# お金の性格診断｜Result / 詳細レポート 情報階層 V1

更新日: 2026-10-05

## 目的
通常Resultを「詳細レポートの無料要約」にしない。
通常Result単体で「うわ、これ自分だ」「誰かに見せたい」が起きる濃さを持たせ、詳細レポートは同じ文章の長文化ではなく、その人物像を解剖する別レイヤーにする。

## 1. 通常Resultの役割
KPIは「分析として正しい」だけではなく、以下の順に感情が動くこと。

1. タイプ名と一言で自分事化する
2. 具体的な生活シーンで「これある」を起こす
3. 自分でも説明しづらかった矛盾を言語化する
4. 強み / ハマりやすい罠 / 攻略法まで読んで納得する
5. 友人に「お前どうだった？」と見せたくなる
6. Chapter 2 の家計クエストへ進みたくなる

通常Resultで最低限見せるもの:
- 8基本タイプ x Primary Style 4 = 32組み合わせ固有の刺さる一文
- 32組み合わせ固有の「これ、ある？」3シーン
- 32組み合わせ固有の人物像タイトル
- 行動を想像できる決断シーン
- 本人が気づきにくい内的な矛盾
- 強み
- ハマりやすい罠
- 攻略法
- NEXT MOVE 1つ
- 3軸は詳細表示として折りたたむ

### 通常Resultでやらないこと
- 数値を主役にしない
- F/I/D/N/M/P の内部コードを表に出さない
- 未測定の性格や生活習慣を断定しない
- 「誰にでも当てはまる」抽象文だけで逃げない
- 詳細レポート用の全解説を詰め込み、読了負荷を上げない

## 2. 詳細レポートの役割
通常Resultの焼き直しではなく「なぜこの人物像になるのか」を分解する取扱説明書。

想定セクション:
- あなたのお金タイプの全体像
- 3軸それぞれの絶対強度 / 相対方向 / バランス状態
- Primary / Secondary Style の組み合わせ解釈
- 軸 x Style の相互作用
- お金を使う前 / 決める時 / 使った後の意思決定パターン
- 金額が大きい時、選択肢が多い時、予定変更時など場面別の出方
- 強みが活きる条件
- 強みが裏返る条件
- 家計管理方法との相性
- 改善を続けやすい仕組み
- Chapter 2 家計診断結果とのクロス解釈

## 3. 家計診断との役割分担
- お金の性格診断 Result: 「自分はどう判断しやすい人か」
- 詳細レポート: 「なぜそう判断し、どう扱うと強みになるか」
- 家計診断: 「実際の家計では、どこに改善余地が出ているか」

性格タイプは家計診断のムダ判定・benchmark・改善額を変更しない。家計診断側では攻略UXと説明の出し方にだけ使う。

## 4. 当たり感コピーのガードレール
具体性は上げるが、測っていない事実を作らない。

OK:
- 「候補が並ぶと、違いを比べて理由に納得してから選びやすい」
- 「こんな場面、ない？」の形で具体例を提示する
- JOB x Style から説明できる決断構造を生活シーンへ翻訳する

NG:
- 感覚寄り = 衝動買いと断定
- 節目確認寄り = 普段は家計を見ない / ズボラと断定
- 特定カテゴリへの浪費を回答なしに断定
- 収入、資産、職業、家族構成など未取得属性から人物像を補完

## 5. シェア設計
スクショまたは共有文だけで以下が伝わること。

- タイプ名
- 刺さる一文
- 代表的な「これ、ある？」1〜2個
- ムダギリ診断の名称

共有の動機は「診断を宣伝したい」ではなく、「これ自分すぎる。お前はどう？」に置く。
