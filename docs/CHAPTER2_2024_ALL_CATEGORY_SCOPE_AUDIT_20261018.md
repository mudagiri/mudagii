# 第2章 2024年公式交差表 × 12カテゴリ 費目範囲監査｜2026-10-18

**対象**：第2章V3.2の「同年代×世帯区分×額面年収帯」の参考負担率を、12カテゴリに広げられるかどうかの一次資料照合。

**結論**：人数区分・年齢・所得・就労区分が一致しても、**支出費目が別物なら「同じ条件の平均支出割合」と表示できない**。既に実装済みの食費・光熱水道・日用品の公表費目ベース参考は維持しつつ、日用品の範囲差などを注記する。残る9カテゴリは **7カテゴリが関連公表項目あり・直接一致なし、2カテゴリは独立項目なし**。実際に存在する統計の数値を「同一母集団の公式カテゴリ平均」として誤用しない。

## データと表示の安全契約

1. **公表セルが存在**≠**診断カテゴリの適切な全国平均がある**。人口母集団が近いだけでは、支出費目・期間・支払主体の同一性は保証されない。
2. 2024年の公表費目率は**各原表セルの平均支出÷同セル平均可処分所得**。個々の世帯の負担率の平均ではない。
3. 年収帯が複数の公表階級にまたがるとき、全セルが原表で確認済み・概数標本n>=50・秘匿なしの場合だけ幅として表示。レンジを公式平均や確率分布と呼ばない。
4. 第1-29表に住宅保有形態・子どもの学校段階・車保有・保険種別などの必要な条件がなければ、別の表の周辺平均を掛け合わせない（FROZEN G03/G07/G13）。
5. **原表平均との差額 ≠ ムダ額 ≠ 改善額**。診断 `confirmedA`、`cUpper`、未来予測、チャプターJOB/STYLE、LINE CTAに統計差を加算しない。
6. 無理に9カテゴリ分の質問を増やさず、結果画面の「ほかの9カテゴリはなぜ平均が出ない？」に理由を折りたたみ表示。食費・光熱水道・日用品には使用した公表費目範囲を明示。

## 次にデータを拡張するための条件

- 通信：スマホ1回線＋付属端末と、統計「通信」との支出範囲を一致させた一次資料（契約料金の同等条件比較）。
- 住居：住居形態（賃貸・持家）を**同時**条件に持つ年齢×年収クロス。第1-17表と第1-29表の独立の平均を掛け合わせない。
- 自動車：保有者世帯だけ、車種・保険・維持費の支出範囲が一致する一次資料。
- 教育：子どもの人数・教育段階・公私が揃うセル、子どもの習い事等の帰属定義。
- 娯楽・美容：用途境界の契約一致と、外食、サブスク、日用品の二重計上排除。
- 保険：保障目的・保険種類・貯蓄性・自動車保険の帰属区分一致。
- サブスク・自己投資：同一費目の公式平均がないため、全国平均との差ではなく、契約見直し（AUDIT型）を維持。
