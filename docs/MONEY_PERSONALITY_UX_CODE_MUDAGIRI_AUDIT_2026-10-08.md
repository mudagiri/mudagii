# ムダギリ診断：第1章UX／コードのムダギリ監査
更新：2026-10-08。対象：`feature/money-personality-pilot`。**FROZEN境界は変更禁止**。

## 目的・判定基準
- ユーザーが最短で「自分のTYPEが分かった」「あるある」「誰かに見せたい」へ進めること。
- JOBとSTYLEの意味が、初見で短い日本語から理解できること。英語は識別子、日本語は意味を伝える本文とする。
- 1回しかない達成演出、押したボタンと遷移先の一致、戻ったら完了した結果を再表示すること。
- CSS削減だけを目的に画像表示、タップ領域、モーション、画面復帰を破壊しないこと。
- 数値改善・共有率の向上はユーザーテスト前に断定しない。

## CSSの整理手順（未完）
1. 実画面の比較基準（390px、690px、Fold実機）を保存。タップ・スクロール・文字の読める大きさ・背景の階層も記録。
2. semantic tokens（紙面／ギルド／ゴールド／文字／JOB個別アクセント）と共通コンポーネントへ整理。
3. `!important` や同一セレクタの重複を、実測で不要と確認できた単位だけ削除。先に大量削除しない。
4. 同じ内容を上書きし続けるCSSは1箇所へ集約。結果カードのJOB固有エフェクトは共通文字CSSと分ける。
5. Before/AfterのVisual Smoke、CSS geometry、実機を比較してから旧CSSを削除する。

## 行動経済学・心理学・マーケティング・共有設計
- 開始前：理解不能な英語・分類説明で長文にしない。診断で何がわかるか、時間・任意追加を明示。
- 完了直後：まず報酬（JOB取得）、次に自己関連性の高いあるある、共有案内を続ける。
- 深掘り：価値観の根拠、強み・注意点・比較、図鑑はスクロールや開閉で探索させる。
- 次の行動：家計診断の主CTAを直接実行させる。まだ未提供のLINE特典で誤誘導しない。
- 仮説はKPIで検証。完了率、結果到達率、SSR閲覧後離脱、シェア開始、共有先復帰、図鑑回遊、第2章移行、STYLE理解率、タイプ納得度をCognitive Pilotで収集。

## 残るゲート
- 最新SHAで Money Personality Validate / 診断本体回帰QA / Visual Smoke を通す。
- 実際の公開Previewのrevision一致を確認し、Galaxy Z Fold7で1周操作。
- LINE URL・特典PDF・GAS本番保存の確認。
- 5〜8人でCognitive Pilot、必要なら文言と配置を修正してから分類のFROZEN可否判断。

## 追補：4視点の導線監査を正式ゲート化（2026-10-08）

**4視点は、コード・文章・画像・CSS・CTAの変更ごとに必ず確認する。** 以下の「行動経済学」は行動障壁と選択構造、「心理学」は自己関連性と納得感、「マーケティング」は価値提案と次行動、「バズ」は共有動機と友人への伝播を意味する。科学的な効果を無検証で断定しない。

| 導線 | 行動経済学 | 心理学 | マーケティング | バズ／拡散 |
|---|---|---|---|---|
| オープニング | まず30問、後から必要な追加だけ。開始時の不確実性を抑える | 正解・不正解を置かず普段の行動を答えてもらう | 「何が分かるか」と時間を先に伝える | 32TYPEは期待感、ただし専門用語で離脱させない |
| 設問 | 1画面1判断・選ぶと進む・復帰できる | 理想像に寄せず、実際の自分をイメージする | 完了率と離脱箇所を監視する | 設問数の水増しや進捗の誇張をしない |
| JOB獲得 | 回答後すぐ報酬を見せ、追加の手間を増やさない | 好意的でユニークなアイデンティティと達成感 | 最初に見せる主役はJOBと日本語の意味 | キャラ付きSSRカード。ただし「限定当選」など偽の希少性は謳わない |
| 結果カード | 情報の優先順位をJOB＞STYLE英語＋日本語＞短い個別説明とする | 「自分のことだ」と感じる具体的な日常行動 | 価値の体験を先に見せ、家計診断に無理につなげない | TYPEを話題にできる見た目と名前を用意 |
| あるある | まず2件、残り4件は希望した人だけ開く | 否定・決めつけ・羞恥表現を避け共感を狙う | 読了の強制をなくし、早くシェアへ | 「これやるw」という日常場面が会話の種になる |
| 共有 | 主操作は画像カード共有、X/LINEは文章・リンクと明記 | 自己表現でき、金額や収入はカードに出さない | SNSごとの動作を誤認させず、未対応時は保存に誘導 | キャラ・JOB名・STYLEの短い日本語・「何タイプ？」・公開用リンク |
| STYLEの詳細 | 英語のまま理解を要求せず、必要時に開ける | 4価値観に優劣をつけない | 診断の納得感を高め、CTAの邪魔をしない | 友人比較でDRIVE等の違いを説明できる |
| 3軸・32TYPE図鑑 | 任意の詳細探索に分離 | 「なぜこのTYPEか」を本人が確認できる | 回遊する人には32タイプを用意し離脱者に強制しない | 類似／対照的タイプの話題、友だちへの再参加導線 |
| 第2章／LINE | 家計診断へ直接進む。LINE登録を必要条件にしない | 性格の診断と実際の支出を混同させない | 「登録不要・12カテゴリ・見直し候補」など提供価値を明確化 | 共有の後にも第2章へのCTAを残す |
| 再訪・復帰 | 回答・結果を保持してやり直しコストを避ける | コントロール感を失わせない | 完了後の再訪を初回開始と混同しない | 外部SNSから戻ってもカードや比較を再閲覧できる |

### 最低限のパイロット計測
- `money-type-funnel-v1.ts`：端末内に匿名セッション単位のイベントだけを最大120件残す。**質問回答・支出額・名前・連絡先・SNSアカウントは保存しない。サーバーへは送らない。**
- `intro_started` / `intro_resumed`：開始・復帰。
- `ssr_claimed` / `result_seen`：獲得完了・結果表示（厳密なUUはsessionIdで集計）。
- `scenes_expanded` / `style_expanded`：共感や価値観をもっと知りたいか。
- `share_attempt` / `share_native_sheet_resolved` / `share_image_downloaded` / `share_text_handoff`：操作の種類を区別。SNS投稿完了数だと誤表示しない。
- `type_book_opened` / `household_cta_clicked`：回遊・第2章遷移の意図。第2章で最後まで完了した人数とは区別。
- 実際の社会的拡散（何人がリンクを踏み何人が開始したか）は**別の匿名参照パラメータとプライバシー監査を設計してから**計測する。広告効果や自然増を機械的に混同しない。

### 検証仮説と禁止事項
- **仮説A**：シェア前の「あるある」を3件→2件にすることで、シェアに到達しやすくなる。実測前に有意な改善を宣言しない。
- **仮説B**：英語STYLEの日本語補足を保つ方が、英語だけより内容が伝わる。理解度を5〜8人のCognitive Pilotで確認。
- **仮説C**：画像カードを最優先にし、SNSごとの挙動を明記する方が、意図した共有をしやすい。シート表示と投稿完了を混同しない。
- **仮説D**：家計診断への中間画面を取り除くと、第2章の実到達率が改善する。第2章での開始・完了ログで確認する。
- 全員にSSRを見せる設計は**演出上のレアカード表現**。希少性や当選率を偽って誘導しない。
- セルフ診断のタイプを医学的・科学的な性格確定と主張しない。
- LINE特典が実際に渡せるまで特典受取ボタンを本番で有効化しない。
- 「シェアで結果が見られる」などの共有強制・友人招待の強制はしない。

### 追加で要確認
