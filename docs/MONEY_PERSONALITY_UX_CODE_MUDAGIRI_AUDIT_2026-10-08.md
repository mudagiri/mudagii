# ムダギリ診断：第1章UX／コードのムダギリ監査
更新：2026-10-08。対象：`feature/money-personality-pilot`。**FROZEN境界は変更禁止**。

## 目的・判定基準
- ユーザーが最短で「自分のTYPEが分かった」「あるある」「誰かに見せたい」へ進めること。
- JOBとSTYLEの意味が、初見で短い日本語から理解できること。英語は識別子、日本語は意味を伝える本文とする。
- 1回しかない達成演出、押したボタンと遷移先の一致、戻ったら完了した結果を再表示すること。
- CSS削減だけを目的に画像表示、タップ領域、モーション、画面復帰を破壊しないこと。
- 数値改善・共有率の向上はユーザーテスト前に断定しない。

## CSSの整理手順（未完）
1. 実画面の比較基準（390px、690px、Fold実機）を保存。タップ・スクロール・文字の読める大きさ・背景の階層も記録。
2. semantic tokens（紙面／ギルド／ゴールド／文字／JOB個別アクセント）と共通コンポーネントへ整理。
3. `!important` や同一セレクタの重複を、実測で不要と確認できた単位だけ削除。先に大量削除しない。
4. 同じ内容を上書きし続けるCSSは1箇所へ集約。結果カードのJOB固有エフェクトは共通文字CSSと分ける。
5. Before/AfterのVisual Smoke、CSS geometry、実機を比較してから旧CSSを削除する。

## 行動経済学・心理学・マーケティング・共有設計
- 開始前：理解不能な英語・分類説明で長文にしない。診断で何がわかるか、時間・任意追加を明示。
- 完了直後：まず報酬（JOB取得）、次に自己関連性の高いあるある、共有案内を続ける。
- 深掘り：価値観の根拠、強み・注意点・比較、図鑑はスクロールや開閉で探索させる。
- 次の行動：家計診断の主CTAを直接実行させる。まだ未提供のLINE特典で誤誘導しない。
- 仮説はKPIで検証。完了率、結果到達率、SSR閲覧後離脱、シェア開始、共有先復帰、図鑑回遊、第2章移行、STYLE理解率、タイプ納得度をCognitive Pilotで収集。
