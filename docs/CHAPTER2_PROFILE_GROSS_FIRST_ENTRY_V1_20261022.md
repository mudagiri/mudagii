# 第2章｜入口の額面年収を主導線に変更（V1 / 2026-10-22）

## 結論
以前「月手取り」画面の任意折りたたみだった年収を、**住居 → 額面年収帯 → 月手取り**の独立したRPGプロフィール工程に昇格。年収の答えがリザルトの公式比較基準へそのまま引き継がれるようにする。月の手取りは負担率の個人分母として残す。

- 二人以上の**家計全体診断**：家族全体の年間額面収入帯（500万円未満 / 500–599 / 600–699 / 700–799 / 800–999 / 1,000万円以上 / わからない・答えたくない）。
- **単身**：本人の年間額面収入帯（400万円未満 / 400–499 / 500–599 / 600万円以上 / わからない・答えたくない）。400万円未満は現行の公式同年代セルの表示対象外（作り物の平均を出さない）。
- **二人以上の生活者の個人負担だけを診断**：家全体の所得帯と本人だけの支出を比較すると対象範囲が異なるため、このモードで世帯額面年収は問わない。結果比較に使う情報が足りないなら無理に補うのではなく、対象外の理由を説明。
- **年収不明も診断継続可**。初期選択なしのまま「次へ」は押せず、明示的に年収帯か「わからない・答えたくない」を選んでもらう。古い途中再開の回答済み年収は値があれば互換扱いする。
- **1,000万円以上は入口で細分化せず、必要な場合だけリザルトで1,000–1,249 / 1,250–1,499 / 1,500万円以上を追加選択**。原表が保証する境界以外には変換しない。
- 単身の選択済み額面は `ProfileDraftV4.singlePeerGrossBand2024` → `ProfileV4.singlePeerGrossBand2024` → `ResultScreenChapter2V32` へ自動引継ぎ。家計全体は `annualIncomeBand` を使用。入り直しの手間を削減。
- 既存の属性ゲート（世帯主年齢の一致、勤労者世帯の該当、原表n>=50）を解除しない。**年収回答だけでは「同条件の平均」と断言しない**。
- FROZEN診断ロジック、`confirmedA`、`cUpper`、GAS、LINE、資産形成第3章、共有画像金額への追加計算は一切なし。

## 4視点設計監査
- **行動経済学**：最初から年収を主画面で尋ねることで、任意詳細に埋もれることによるデフォルト無回答を抑える。高額所得を入口で細分類し過ぎて選択疲れを増やさない。答えたくない選択で心理的圧迫を避ける。
- **心理学**：本人と家計の額面の意味の違いを見出しで説明し、正しい比較者に近づく納得感を上げる。「高い/低い」と評価せず、公式統計の参照先を決めるための入力だと伝える。
- **マーケティング**：診断結果を見たあとに再入力を求める摩擦を減らす。一方で追加1画面による診断離脱率を注視し、年収回答率の改善とトータル完走率・面談予約CVのトレードオフを実測で判断。
- **バズ理論**：比較表示の「当たっている感」は年収の適切な母集団照合で作る。ただし推計や平均との差を「ムダ」「削減額」として盛らない。RPGの語り口・ムダギリくんのポーズを既存アセットで統一し、SNSカードに年収は載せない。
