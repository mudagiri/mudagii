## 単身世帯：公式の観測値（就業状態を限定しない）
単身世帯では第2章で額面年収を必須入力にしない。利用者が結果画面で**任意に**7つの公式所得階級から1つ選ぶと、その公表区分の食費平均を出す。選択はReact状態のみ。ローカルストレージ・GAS・LINEには記録しない。

| 年収階級 | 年間平均食費(円) | 集計世帯数 |
|---|---:|---:|
| 100万円未満 | 453078 | 42 |
| 100〜200万円 | 483780 | 219 |
| 200〜300万円 | 585050 | 177 |
| 300〜400万円 | 605088 | 78 |
| 400〜500万円 | 641156 | 49 |
| 500〜600万円 | 655075 | 32 |
| 600万円以上 | 832953 | 49 |

単身の公表階級は**600万円以上で頭打ち**。年収1,000万円、1,500万円の人に「同じ年収の平均」と誤認させない。各所得帯の集計世帯数が小さいため、個人の適正額や削減余地を断定しない。

## G01〜G13 を破らない表示ルール
- 主軸：単身は年齢、二人以上は世帯人数、光熱費のみ人数×地域×季節の既存MODEL。主軸は所得参考値によって上書きされない。
- 補助軸：独立の「所得階級別の食費平均」。同一年の同じ母集団の公表セルだけ使い、**同年収×同世帯人数×同年齢×同地域**とは主張しない。年収×人数の交差表も捏造しない。
- 丸め：各原表の年間平均額 / 12 → Math.round (月額)。同年収範囲の複数公表区分について最小と最大を出す。金額の月額換算は将来節約額ではない。
- 一致条件：2人以上世帯の参考値は `profile.diagnosisScope='household'` かつ年収帯が回答済みの場合だけ。個人負担と二人以上世帯総額を比較しない。
- 単身の年収は本人の選択のみ。**本人入力の月手取りから額面年収を逆算しない**。
- `confirmed_saving`、`cUpper`、判定ランク、シェア画像は一切変更しない。平均との差から改善額を算出しない。
- UIの見出し・注意書き・出典ボタンは比較一覧の前に提示。閉じられるのは出典詳細だけ。
- サブスク・自己投資・車の平均を勝手に補填しない。別カテゴリで所得参照を導入する場合も独立した統計原表と母集団・対象範囲の照合を必須とする。
