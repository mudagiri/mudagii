## 2. 重要な実証：horizonを変えたとき本当に変化があるか

**同じC1/C2、同じ目標、同じ条件を維持して「1〜3年」→「10年以上」にだけ変更**：

- 住まい \`home\`：契約更新/住み替えの直近の検討 → 守りたい住環境・遠い将来の条件整理。**\`rent\`の実契約条件を知らなければ断定度を落とす**。
- 旅行・趣味 \`travel\`：近い旅行の必要費用 → 長期の趣味目標と現在楽しんでいる支出の両立。
- 資産形成 \`invest\`：短期の使途/現金維持に関する確認 → 長期の目標と必要余力の整理。**短期だから全金融商品不適合/長期だから株式適合としない**。
- 独立・挑戦 \`challenge\`：必要な初期費用を早めに確認 → 先に小さな準備を積む。**起業に向くとは断定しない**。
- 教育 \`family\`：次の教育関連イベント/費用を確認 → 長期の教育希望を整理。実際に子どもがいるか別途確認。
- もしもの備え \`safety\`：直近の不足/重複の確認 → 将来のライフイベントで見直す条件を整理。
- 老後 \`retirement\`：退職時の収入と支出の確認 → 退職時期と守りたい暮らしを定義。
- 未定 \`undecided\`：**目標が不明なまま期限だけ変わっても、本人の最初の一手を信頼して個別化できない**。このケースは不合格に留める。

### 情報量の限界

\`goalHorizon\`はユーザーの「希望の時期」。\`debtAmount\`、\`liquidAssets\`、\`freeTimeHours\`、\`careerOptions\`、\`riskCapacity\` が無いなら、**金融・職業の最適選択の優先順位は分からない**。RPGで高精度に見せるのは禁止。

## 3. QUEST 3の動的追加のルール

**原則：最大1問追加するのは、異なる回答で初手が実質的に変わるときだけ。** 言い回しだけ変わる、面談に誘導するためだけ、診断を豪華に見せるためだけなら出さない。

| ゲート | 発動条件（両方必要） | 追加で聞くこと | 回答で変わること |
|---|---|---|---|
| Q3-G1 | 独立・挑戦目標＋挑戦内容が不明で次の一手を選べない | 何を始めたい？（事業/学習/趣味/未定） | 初期費用を確認／時間・学習準備を確認 |
| Q3-G2 | 収入増目標（C3新規選択）＋「やり方」が分からない | 現状の制約で大きいのは？（時間/技能/働き方/不明） | 昇給条件の確認／技能の収益化条件／外部の仕事可能性の検討 |
| Q3-G3 | 自由時間目標＋時間の実際の用途不明で、具体行動が変わる | 時間を一番使うのは？（仕事/家事/移動/その他/不明） | 労働負荷/委譲/動線の確認 |
| Q3-G4 | 資産形成/老後目標＋\`horizon=near\`だが使う予定の資金が不明 | 1〜3年以内に使う予定のあるお金は？（ある/ない/不明） | まず近い資金の区分を確認／必要余力の確認 |
| Q3-G5 | 目標未定＋目標候補が最低2つあり、選択で実行行動が変わる | その2つなら、先に取り組みたいのはどちら？ | 初手に何を載せるか |
| Q3-NONE | それ以外、または回答しても出力に意味ある差がない | **何も聞かない** | RPG演出だけ進める |

**制限**：
- 追加は1人につき**最大1問**。ゲートが複数当たれば**本人の選んだ目標に直接関係する1問**だけ使う。
- 「よく分からない」は常に妥当な回答。回答が不明な場合は結論を弱める。
- 最終提案を変える根拠が依然不足していたら**未確認として返す**。面談なしでは何も分からないという強迫を作らない。
- Q3の発動率はまだ不明。必須に近くなったら多すぎるので再設計。C2から引き継いだ情報で不要な場合は省く。
- 旧Draft 0.5の\`使える資金があるかも\`という自己申告だけで投資可能額と推定しない。
