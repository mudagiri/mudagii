# 第2章｜2024年原表 年収50万円階級のずれ修正と関連7費目の拡張（2026-10-21）

## 結論
2024年全国家計構造調査第1-29-1表の**元Excelの50万円階級の列と既存の転記コードの階級ラベルに１階級（50万円）のずれがあった**。今回、元原表のSHA-256および実際の列見出しから数値・階級を自動生成するよう変更した。高所得の再掲列BB/BC/BDはこの問題の対象外。

統計の交差参照を12カテゴリへ拡張する前に、この不整合を**食費・光熱費・日用品の既存3カテゴリでも必ず修正**。対象年齢・勤労形態・額面年収が一致しない場合は参考率を出さない。

- 公式単身 a010293.xlsx, SHA-256 `62648369c8f550afb849575d34bb4a8ed3935c7b8d7dcc8f28bde7ecbdfe16a2`

- 例・二人以上の勤労者、世帯主30–39歳、400～450万円：公式原本 U列は集計概数n100、食費67,858円、平均可処分所得303,972円。旧転記では400～450万円を**原本T列の食費60,183円・n60**に紐付け。旧数値を訂正。

## 実装方式とゲート
1. `scripts/extract-chapter2-official-peer-original-2024.py` は元ExcelをSHA一致で取得し、原表ラベルを列ごとに検証。
2. `scripts/generate-chapter2-2024-50man-aligned-v2.py` は、その原表の**印字されている所得列名**を正本にして `official-2024-50man-aligned-worker-v2.ts` を生成。79行（全国二人以上58、単身21）の有効 `n>=50` セルを保存。X/欠損や低標本を補間せず除外。
3. `age-income-joint-multi-2024-official-v1.ts` と `age-income-joint-burden-gate-v1.ts` は生成された**同一の正本**から既存APIをマップし、別々に手転記しない。
4. `chapter2-official-related-2024-middle-single-v1.ts`：通信・自動車関係・教養娯楽／交際・美容服飾・家賃・保険・教育の7分類に関連する11原表費目を同じ年齢／年収／世帯区分／概数標本n>=50の元セルから取り出す。
5. 世帯年収500–599/600–699/700–799/800–999万円は、2または4の50万円刻み**公式公表セルの率の最小～最大**として出し、100万円帯の単一公式平均や個々の世帯のばらつき幅を偽装しない。二人以上世帯は世帯主年齢の一致確認も必須。単身は本人年齢を世帯主年齢として参照し、勤労者確認は必須。
6. 単身の高所得は低標本・階級不一致につき非表示、単身の教育は子どもの学校段階と比較不可能なので独立の関連率を表示しない。サブスク／自己投資も公表単独費目なし。
7. 旧2025年の係数を掛けた推計値は**研究専用で継続HOLD**。年収階級訂正による旧モデルとの照合値も再計算が必要で、旧の中所得49セル/食費MAPE12.93%は無効。元セル訂正後の中所得48セルでは食費MAPE10.84%/WAPE10.22%/平均符号付き誤差+9.46%、光熱水道MAPE7.85%/WAPE7.39%/同+6.78%。これは2025モデルの2024観測との参考バックテストであり予測性能の証明ではない。
8. 保存済み確定改善額・未確定上限・見直し候補ランク・GAS・LINE・シェア金額、FROZEN判定本体には一切統計から変更を加えない。ユーザーと関連公表費目の支出スコープは違うので、本人平均との差は算出禁止。

## 後工程・入口の年収質問
既存は月手取りが主質問で、年収は任意折りたたみ。入口で単身本人/家計全体の額面年収を先に大枠で聞き、本人が「分からない・答えたくない」を選べる仕様への変更は**後工程**。今回は統計照合・表示の誤り修正を優先し、プロフィールV4構造を改変しない。高額所得1,000万円以上の細分化は結果で追加確認。
