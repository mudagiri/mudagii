# 第1章×第2章｜4STYLE答え合わせ V1.3 商品監査と採用条件

更新：2026-10-12／**Draft PR #46内の隔離Pilot、未FROZEN、診断コア・GAS・実相談導線変更なし**

## 今回確認したこと

第1章のお金の性格診断は、4STYLE（前進/楽しさ/安心/納得）と3軸（時間/判断/把握）を測る。第2章の実額/満足・目的・契約確認はそれらと同じ変数ではない。**性格の「的中率」、客観的な一致率、家計の正しさは計算できない。**

ただし、**同じ利用者が2つの診断で回答した「大切な価値」と「現状の具体的な行動課題」**を、本人申告の範囲で重ねることはできる。

## 4STYLE × 第2章12カテゴリの採否

| STYLE | 根拠があれば表示するヒント | 具体的な条件 | 禁止する飛躍 |
|---|---|---|---|
| DRIVE（前進） | 自己投資に目的があり守りたい／自己投資が惰性になったと本人が回答 | `selfDevelopment` が既知で有額、目的/結果＋protect または inertia＋cut | 前進型なので高所得・自己投資すべき・成果が出ている |
| ENJOY（楽しさ） | 満足している娯楽を守る／娯楽の惰性・不満足を見直す | `fun` が既知で有額、満足＋protect または waste/inertia | 楽しさ型は浪費・旅行好き・外食費が多い |
| SECURE（安心） | 保険の目的が不明確／最後の保障内容の確認が古いことに気づく | `insurance` が既知で有額、purpose unclear または lastReview over3y/never、V5 optimize | 保険加入・保障増額が必要／安心型の性格と保険保有は一致する |
| OPTIMIZE（納得） | 未使用かつ解約可能と確認した契約を見直す | `sub` に既知の有額支出・未使用分・解約可能確認・`aAmount>0`・cut | コスパ型はケチ／高い契約が必ずムダ／解約で現金確保済み |

**全12カテゴリを機械的にSTYLEにマッピングしない。** 例えばSECURE×保険が満足してprotectでも、性格的中とは扱わず「現段階では比較できない」とする。生活状況に由来する支出は性格の外部検証ではない。

## 2枚比較の意味

本人が守りたい支出と、未使用・解約可能という**独立した確認済み改善機会**が同一診断に存在するときだけ、実際の金額2枚を並べる。

- DRIVE：目的ある自己投資を守る＋未使用サブスクを確認
- ENJOY：満足している娯楽を守る＋未使用サブスクを確認
- OPTIMIZE：本人が守ると答えた娯楽＋未使用サブスクを確認。ここでは「納得した支出の対比」という行動選択であって、`fun` がOPTIMIZE性格の的中材料になるという意味ではない。
- SECURE：**今は対応する2枚比較を作らない**。保障加入額や保険目的を「守る金額」として安易に置かず、目的の確認に留める。

比較表示の安全条件：同一匿名ユーザー、C1ハンドオフが正規、C2の12カテゴリ完成、重複なし、既知支出で`v5Status=protect`、別カテゴリサブスクの未使用・解約可能・`v5Status=cut`、`0<aAmount<=subUnusedAmount<=sub.amount`、実数/安全整数の検証。未回答または不整合なら2枚比較を作らない。

**左は月額の支出、右はまだ実行していない改善機会。差し引き・合計・投資余力化をしない。** C2の確定/未確定意味論はそのまま維持。

| 観点 | 今回の狙い | 反証の条件 |
