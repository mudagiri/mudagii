## 4. 「次の攻略ポイント」決定ルール V1.3

### 入力の出所と確かさ

- **FACT_CH1**：ID照合済みのJOB・STYLE（人格の優劣／投資適性の根拠にしない）。
- **FACT_CH2**：実在する診断結果に対応した家計の回答、12カテゴリ判定。金額の意味はソース仕様を維持。
- **SELF_REPORT_CH3**：本人が申告した希望・時期・状況。「検証した」は本人の申告であり、資産計算済みの証拠とは異なる。
- **CALCULATED**：入力値・計算式・仮定条件が揃った場合だけ表示可能。利回りなどの不確実な予測は保証しない。
- **UNKNOWN**：入力なし／対象外／未検証。「ゼロ円」や「問題あり」と同一視しない。

### 意思決定の順序（説明可能なルール）

1. **Identity gate**：匿名ID、sessionId、diagnosisIdの整合を検証。不一致の他人情報を一切流用しない。未取得は新規質問から復帰できる。
2. **Goal gate**：C2 goalが有効なら使用、未回答なら1画面だけ尋ねる。C3で変更可能にする。`undecided`は正当な選択肢。
3. **User intent gate**：ユーザー自身が「まず知りたい」を選んでいれば、その疑問を尊重する。金額や危険度を断定する要求には、追加条件が必要だと説明する。
4. **Readiness gate**：目標像、希望時期、概算費用、現在の準備、比較・検証の有無を**各々独立して**扱う。すでに確認済みの内容を問題化しない。
5. **Evidence gate**：同じ論点についてソースで確かめられる情報を列挙。情報不足なら不足額・投資可能額・達成率を作らない。
6. **One-next-step gate**：表示する主アクションは原則1つ。根拠となるユーザー回答を直前に表示し、他の論点は詳細へ折りたたむ。
7. **No-created-pain gate**：全項目が確認でき、本人に追加の相談希望がなければ「今の準備を大切に／必要時に再点検」で完結させる。面談CTAを強制しない。

同点時の決定：本人が選んだ疑問→関連する最も早い予定→回答負荷の少ない確認→なお同点なら本人に選んでもらう。「重要度スコア」は科学的根拠のない数値を捏造しない。

### 擬似ロジック（実装前の説明用）

```ts
function decideNextStep(input: ValidatedChapter3Input): QuestInsight {
  // Source evidence and safe unknowns are required.
  if (input.goal == null) return askForGoal();
  if (input.explicitQuestion) return answerOrRequestEvidence(input.explicitQuestion);
  const unknowns = goalSpecificMissingVariables(input.goal, input);
  if (unknowns.length === 0) return celebratePreparedness(input);
  return recommendOneVerifiableStep(unknowns, input.goal, input.selfReportedPreferences);
}
```

「最優先」という表現は医療や法務上の優先度の断定ではなく、本人の目的に対する**最初の確認項目**という意味で使う。

### 会話にJOBとSTYLEを使う境界

- **使用可**：JOB画像・固有色・キャラクター登場、STYLEの語り口や例え（過度の類型化はしない）。
- **使用不可**：JOBから希望する人生、貯蓄額、危険度、投資商品、面談必要度を推測する。
- **例**：直感魔導士＋本人が旅行を選択 →「あのとき見つけた宝箱、今はまだ未鑑定だ。君が選んだ『旅行』に使えるか、一緒に確かめよう」。
- **整合**：第2章で`protect`のものは「守る」。`cUpper`は「まだ確認が必要な宝箱」。`confirmedA`は「確認できた改善額」。両者足し算不可。

### 3章の一続きの会話（仮想例）

- ギルド門「直感魔導士、おかえり！12カテゴリの鑑定、よくがんばったな！」

## 6. 報酬とシェアを分ける

- **個人リザルト**：「未来の羅針盤」獲得演出→「未来攻略書」詳細。表示：JOB、2章の戦果（確定/候補別）、本人の希望、守りたいこと、根拠、気づき、一つの次アクション、任意の試算、相談テーマ。
- **共有カード**：JOB公式画像＋第3章クリア印＋未来の目的地を抽象化したアイコン（希望があれば非表示）＋サービス名。**氏名・具体的家族情報・資産額・支出額・診断ID・相談テーマは一切なし**。
- **共有CTA**：ネイティブシェアを主、SNS別を補助（または切替）。機能の重複で迷わせない。シェアしなくてもリザルト・次章操作が可能。
- **将来の数字**：簡易算術（例：旅行36万円/年なら月3万円）は根拠付きで表示可。実現可能性・リターン・不足額は資産・時期・税等の条件が不足していれば表示禁止。

## 9. 仮想QA・Cognitive Pilot ゲート（**未実施**）

### 決定表の自動テスト要件

**8ゴール × 4状態＝32件**を最低カバーする。

- 状態1：目標像はあるが時期/費用未確認 → 情報不足の一歩。金額捏造なし。
