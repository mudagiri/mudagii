# 第2章比較資産の再利用監査｜所得・月手取り・12カテゴリ
監査日: 2026-10-16 / 対象: PR #47 (最終契約候補)・PR #50 (本番V5 UI限定)

## 症状と直接原因
1. 属性別の公式支出目安（年齢・人数・地域・季節等）は `resolveComparableV2` / `benchmark-router-v4` から Result VM に届いているが、所得に対する負担の強弱は結果に届いていなかった。
2. `ProfileV4.monthlyTakeHome` はプロフィール入力と旧診断エンジン `runDiagnosisAdapterV3` には存在。にもかかわらずV5/V3.2の12費目リザルトで「各費目÷同じ対象範囲の本人月手取り」を表示していなかった。
3. 比較デモは一時、所得を替えても同じ比較目安・同じC上限を返した。これは最終契約に沿う一方、家計負担の第2レンズが見えないため「高所得との差がない」と映った。
4. 旧 `comparable-resolver-v1.ts` には二人以上・勤労者世帯の所得階級別参考支出表と係数あり。しかし最終契約では独立した人数別参考値に旧所得係数を掛けて架空クロスを作ることは禁止。残すべきは**独立した所得階級別の参考位置**であって、旧係数の本番復活ではない。
5. 2025年頃の `prefavg` / `prefavg2` / `gpt_input` の負担率表は会話上の設計記録にあるが、現物・分母・母集団・集計年が未照合。食費25％等を公式平均としてUIに表示してはならない。

## リザルトの4つの別レンズ（意味論を混ぜない）
| レンズ | 分子 / 比較軸 | 状態と表示 | 値の用途 |
|---|---|---|---|
| A 金額の市場位置 | 対象スコープ一致の月支出 ÷ 公式/モデル参考月額 | 既存 `comparable`, `comparisonQuality`, `comparisonContext`, `sourceVersion`。DIRECT/MODEL/AUDITを区別 | 似た属性の支出参考位置。差額はムダや削減額ではない |
| B 本人手取り負担度 | **本人の同一診断範囲の支出 ÷ 本人入力の月手取り** | PR #47/50で `incomeBurden` を追加。12費目でN/A・未把握・スコープ違いを区別 | 暮らしへの重さ・家計余力を見る。統計平均ではない |
| C 所得階級別市場参考位置 | 同一の公式統計表内の年収階級別・費目別支出 | 旧V1に原票系列あり。最終契約では参照専用。**未公開・原票再照合が必要** | 所得階級に応じた買い方・市場支出の独立参考。人数×所得の掛算は禁止 |
| D 同一母集団の平均負担率 | 公式の同じ世帯群・同じ年次・同じ階級の費目支出 ÷ 可処分所得 | 2025家計調査・用途分類の可処分所得と支出を原票同一セルで照合後に作成可能。旧単純割合表の真偽は未照合 | 『平均負担率との比較』と呼べるのはここだけ。分子/分母の母集団相違時は表示禁止 |

## 12カテゴリ利用状況（正本 `MASTER_ENGINE` 優先）
| カテゴリ | A: 正本比較条件 | B: 本人月手取り比 | C/D所得参考の扱い | C上限 / CONFIRMED |
|---|---|---|---|---|
| 住居 | 民営賃貸×地域。ローンは別スコープ | 本人/家全体の診断額のみ | 金額参考と手取り負担を別々に | 住居市場差から自動削減なし |
| 通信 | 大手/MVNO料金帯。回線・ネット・端末分離 | 同じ診断額のみ | 範囲確認なしの所得平均は出さない | スマホ1回線の条件付き上限。確定でない |
| 光熱・水道 | 単身=年齢。複数=人数×地域×月 MODEL | 同じ診断額のみ | 所得クロス合成禁止 | 継続的な上振れと回答した場合だけC候補 |
| 保険 | 保障範囲と個人/世帯。V5で市場位置別レンズあり | 診断額÷同じ範囲の手取り | 年収階級参考の二次レンズは主比較と合成しない | 保険料市場差だけで削減額なし |
| サブスク | 使用・重複・停止可否（架空平均禁止） | 手取りへの実負担は表示可 | 全国平均負担率なし | 不要＋解約可能が確認できた額のみA |
| 食費 | 単身=年齢、複数=人数。所得五分位参考は独立 | 手取りに対する食費割合 | 所得階級別費目支出は別レンズで提示余地あり | 満足度・範囲・上限条件を適用、差額全額は不可 |
| 日用品 | 単身=年齢、複数=人数、商品重複除外 | 同じ診断額のみ | 所得階級別は別の母集団として分離 | 恒常性を確認してからC |
| 娯楽・交際 | 月次コア。旅行/宿泊等の時点差を分ける | 同じ診断額のみ | 旧100ケース総額と現行コアを混同しない | 満足度と継続契約の確認が必要 |
| 美容・服飾 | 単身=性別×年齢、複数=年代 MODEL | 同じ診断額のみ | 同時クロスのない疑似平均は禁止 | 本人の価値・満足度を優先 |
| 車 | 使い方/維持費の契約監査、AUDITが基本 | 同じ診断額のみ | 保有者平均の捏造禁止 | 市場差だけで削減額なし |
| 教育費 | 子人数×学校段階×公私 | 同じ診断額のみ | 世帯所得×学校種別の架空クロス禁止 | 家族の方針・具体案なしの削減なし |
| 自己投資 | 目的・利用状況・成果の監査 | 同じ診断額のみ | 全国の架空平均は作らない | 金額だけの削減なし |
