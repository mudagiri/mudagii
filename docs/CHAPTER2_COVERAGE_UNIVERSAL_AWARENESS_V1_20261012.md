# 第2章｜保障の棚卸し・全STYLE共通カード V1（2026-10-12）

**現在地：Draft PR #46の隔離試作。診断ロジック・家計金額・GAS・LINE・面談予約は未変更。**

## ユーザーの正式な意図
「保障に関する見直しは基本全員に認知させたい。内容把握してるとか見直ししたばっか以外は」

保障を点検する理由は安心タイプに限らない。第1章のSTYLEから必要保障額・契約の良否を決めつけない。保険商品・増額・解約への誘導ではなく、**本人が保険内容や公的保障を確認する自発的なきっかけ**を短く渡す。

## 第2章の既存データとの整合

`RpgBlock1.tsx`：月額の保険料がある時だけ「今入ってる保険、内容ちゃんと把握してる？」と聞く。
- `insurancePurpose='clear'`＝「目的も保障内容も把握してる」と本人が回答。この場合、設問仕様上、**見直し時期は追加で聞かない**。だから`insuranceLastReview`が空欄でも誤って未見直しとみなさない。
- `insurancePurpose='mostly'|'unclear'`の場合だけ「最後にちゃんと見直したのは？」を質問する。
- `insuranceLastReview='within1y'`＝最近確認している、と回答。

## 全STYLE共通の表示条件

| 回答・状態 | カード | 方針 |
|---|---|---|
| 保障目的と内容を把握している `clear` | **出さない** | 直近見直し時期が未入力でも把握の回答を尊重 |
| 1年以内に見直した `within1y` | **出さない** | 大まかな把握でも、直近見直しを回答した場合は繰り返し案内を控える |
| 一部だけ把握 `mostly`／直近1年以内でない | **出す** | 目的・保障額・期間を簡単に確認 |
| 目的が曖昧 `unclear`／直近1年以内でない | **出す** | 保障証券で対象・金額・期間を確認 |
| 3年以上前／未見直し／不明 | **出す** | 暮らしや勤務状況の変化と照合 |
| 保険料0円 | **中立に出す** | 会社・家族・公的保障も含めて備えの確認。新規加入は勧めない |
| 保険料の入力対象外 `na` | **中立に出す** | 保険がない／保障不足と決めつけない。対象外と0円を混同しない |
| 未回答・把握不明 | **出す** | 加入有無や資料を確認する入口 |
| 第2章の保険カテゴリ自体がない／重複 | **出さない** | 不完全・不正入力から架空の判定を出さない |

**対象範囲：DRIVE／ENJOY／SECURE／OPTIMIZEすべて。**

## UI配置と理由

`ResultScreenChapter2V32.tsx` の**戦果報告と敵の報告後・次のライフプラン相談CTA前**に、小さな `CoverageAwarenessCard` を挿入。未確定の1年・5年・10年の「ドーンと見せる」累計の前には割り込まない。

見出し「🛡 保障の棚卸し」。大事な1件と「まずはこれだけ」だけを最初に表示。必要なら「保障を確認する理由」を開ける。相談は強制せず、従来のライフプラン面談への導線に変更なし。

既存のSECURE×保険の`chapter12-answercheck-experiment-v1.mjs`照合ロジックを除去して、**同じ確認を性格の一致判定と全STYLEの保障確認で2回見せない**ようにした。

## 重要な禁止事項

- 保障に関する見直し＝保険料の削減機会、ではない。**`confirmedA`／`cUpper`へ金額を一切加えない。**
- 高い保険料＝ムダ、低い保険料／未加入＝保障不足とはしない。
- 「保険に入るべき」「今の保険は必要ない」「保険料が◯円浮く」と誘導しない。
- 第1章の性格で保険の必要額や商品適合性を判定しない。
- 家族・個人の保障詳細をSNSや性格専用GASへ送らない。
- 専門家への相談は本人の自由意思。LINE友だち追加のみをCVと誤認しない。
