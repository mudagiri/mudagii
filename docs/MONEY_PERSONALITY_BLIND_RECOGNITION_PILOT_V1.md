# ムダギリ第1章｜自己一致／隣接タイプ識別 Pilot V1
更新: 2026-10-09

## 目的
「当たっている気がする」（一般論による同意）と「実際に自分の説明を他タイプより選べる」（タイプ間識別）を別々に観測する。第1章の候補を改変して都合よく当てにいかない。

## 5〜8人のCognitive Pilot
1. 初見のスマートフォンで最初から受験。開始・完了時刻と中断場所・実回答画面数を計測（記録は匿名化）。
2. 結果のJOB画像、短いHero、最初のあるある2件まで見て「自分らしさ0–10点」を自由記述理由付きで回答。
3. 心当たりがない場面にチェック（未経験/経験したが違う/文章が意味不明）。この3つは別の失敗モード。
4. 次にTYPE名を隠し「本人の結果と、1軸だけ違う近接タイプ2つ＋STYLEだけ違うタイプ1つ」を、順序をランダム化して読んでもらう。どれが一番自分に近いか・迷った候補・理由を記録する。
5. 診断前と診断後のライフプラン相談信頼感、家計診断へ進みたい気持ち、シェア意向（各0–10）を測り、結果の印象を深掘り。
6. 第2章への遷移／戻る／LINEプレビュー／シェア（キャンセル含む）を実機で確認。予約クリックは「予約確定」とは数えない。

## 30〜50人のブラインド再評価
- 3軸の境界ラベル（BALANCED/LEAN/CLEAR）とSTYLE近差で層別化し、近差の人も含むサンプルにする。
- 評価者に「正解となるタイプ」を教えない。1人が複数ペルソナを演じて得点を増やさない。
- 本人タイプがトップ選択された率と、上位2説明が僅差だった率を分けて集計。近差・初手シーン一致・生活場面未経験別にみる。
- 0–10の自己一致スコア、タイプの選び直し意向、家計診断への到達を別にする。
- 同一人物の再受験は回答環境・間隔を記録。仮想ノイズテストと実再検査一致を区別する。

## 守るべき判断
- 32TYPEの見かけの完全一致率だけでタイプ数を減らさない。
- 高い共感率を作るために診断スコアや境界を後付けで動かさない。
- タイプを強く断定して恥・不安を煽らない。
- 5〜8人は不具合発見向け。小標本で統計的な妥当性を断定しない。
- LINEは任意。最終CVはライフプラン相談の「予約確定」。
