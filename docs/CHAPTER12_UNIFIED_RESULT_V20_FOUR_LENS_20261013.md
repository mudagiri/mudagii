## 実装仕様（データ意味論は不変）
1. **進行表示**：第1章と同じ `MUDAGIRI QUEST LOG`、第1章JOB獲得→第2章家計バトルの2段階。第1章の正当なhandoffがない場合に「第1章クリア」を偽らず「未連携」とする。
2. **第2章冒頭JOBの継承**：結果金額より前、QUEST CLEAR!の直下に獲得済みJOBを一度だけ表示する。第1章と同じ正本`JOB_CHARACTER_ASSETS`から画像・色・名前を取る。4STYLEは前進・楽しさ・安心・納得（変更は表示だけ）。第1章を通っていない場合はJOBを作らない。
3. **同じ案内役**：第2章の冒頭でムダギリくんが「そのJOBで家計バトルもクリア！一緒に戦った戦果を見よう。」と語る。第1章のクリーム色吹き出しと同じ視覚文法を用い、説明や戦果に介入しすぎない。
4. **明暗のリズム**：RPG背景の下、宝箱・未来の戦利品は暗い演出のまま。候補理由・入力額・比較目安・次の確認は、第1章の明るい羊皮紙風の「読み物」に変える。各内訳の二重枠を消し横罫線で区切る。情報は削らず、初期表示で全件読む。
5. **CV/プライバシー**：一般ライフプラン相談は金色の主導線、保障相談は青緑の明示的な副導線。未確定候補≠節約実績、診断根拠/計算ロジック不変、SNSカードに財務・保険情報を含めない。

## 行動経済学／心理学／マーケティング／バズ理論の4視点

| 視点 | ねらい | やりすぎないための反証・注意 |
|---|---|---|
| 行動経済学 | 冒険の進行と結果を一目で関連づけ、確認候補の全件根拠を「読む」情報として提示 | 冒頭JOBが大きすぎて月額の未確定注記・次アクションが見えない場合は縮める |
| 心理学 | 獲得したJOBを次章の主人公として持ち込み、ギルドと会話の同一性を作る | 第1章未完了なのにJOBやクリアを装わない。保障で恐怖・解約を煽らない |
| マーケティング | 戦果→見直し根拠→未来→相談という順序とCTAの主従を保持 | 単なるLINE友だち追加を面談予約・相談成立として数えない |
| バズ理論 | 人に見せたくなるJOB・キャラの一貫性と共有カードの物語を守る | 家計金額・収入・保険の情報を共有カードに載せない |
