## 実装仕様（データ意味論は不変）
1. **進行表示**：第1章と同じ `MUDAGIRI QUEST LOG`、第1章JOB獲得→第2章家計バトルの2段階。第1章の正当なhandoffがない場合に「第1章クリア」を偽らず「未連携」とする。
2. **第2章冒頭JOBの継承**：結果金額より前、QUEST CLEAR!の直下に獲得済みJOBを一度だけ表示する。第1章と同じ正本`JOB_CHARACTER_ASSETS`から画像・色・名前を取る。4STYLEは前進・楽しさ・安心・納得（変更は表示だけ）。第1章を通っていない場合はJOBを作らない。
3. **同じ案内役**：第2章の冒頭でムダギリくんが「そのJOBで家計バトルもクリア！一緒に戦った戦果を見よう。」と語る。第1章のクリーム色吹き出しと同じ視覚文法を用い、説明や戦果に介入しすぎない。
4. **明暗のリズム**：RPG背景の下、宝箱・未来の戦利品は暗い演出のまま。候補理由・入力額・比較目安・次の確認は、第1章の明るい羊皮紙風の「読み物」に変える。各内訳の二重枠を消し横罫線で区切る。情報は削らず、初期表示で全件読む。
5. **CV/プライバシー**：一般ライフプラン相談は金色の主導線、保障相談は青緑の明示的な副導線。未確定候補≠節約実績、診断根拠/計算ロジック不変、SNSカードに財務・保険情報を含めない。

## 行動経済学／心理学／マーケティング／バズ理論の4視点

|---|---|---|

## V2.0.1｜「いつかやりたい」を今日できる一歩へ
2026年10月13日、ユーザーから「後回しの積み重ねが、後年の後悔になる」という考え方を、第1・第2章の連続する体験で気づかせたいとの示唆があった。出典記事の「老後の後悔ベスト1」という見出しを統計的順位として引用・訴求しない。焦りや年齢不安を煽るCV設計にも使わない。

**実装方針**：すでにある「次の冒険は、未来の作戦会議。」の説明文を短く改めるだけ。新しいカード、同意画面、質問、選択肢を増やさず、無料ライフプラン相談ボタンの文言と保障LINEの別導線を維持する。
- 見直し候補あり：「{主要候補}が本当に見直せるか、一緒に確かめよう。『いつかやりたいこと』を、今日できる一歩に変える作戦も考えよう。」
- 候補額未特定：「無理に削らず、今の家計を守りながら考えよう。『いつかやりたいこと』を、今日できる小さな一歩につなげよう。」

行動経済学：今日の小さな行動という足場を示すが強制しない。心理学：自律性を守り、まだ希望が決まらない人も排除しない。マーケティング：売込みと捉えられない自然な将来相談への橋を架ける。バズ理論：ユーザーが自分の言葉として使える「いつかやりたい」を採用し、家計・年齢・契約等の個人情報を共有物には含めない。インタラクティブ計測は増やさず既存のCV/面談の観測を優先する。

**検証**：`qa-chapter2-v32.ts`で候補あり／候補無しの双方で非脅迫的な文言と金融額の分離を監査。スマホ8環境QA、公開SHA照合と実人間の理解確認をマージ前のゲートとする。


## V2.0.2｜「できていない」より、今「できる」に注目する

ユーザーが共有した2026-10-11付記事『なぜか人生がうまくいかない人の特徴・ワースト1』は「できないことの列挙より、今できることに集中する」という行動哲学の参考。記事タイトルの順位付けや、利用者に学習性無力感があるという判断を、科学的根拠・診断・マーケティングの煽りとして扱わない。

- 第1章：自分のお金の強み・価値観を発見する（既存のまま）。
- 第2章：削れる候補だけを責めず、「守る」「そのままでOK」と判定されたカテゴリも戦果とする。ただし**実際の回答行にその状態があるときだけ**案内役が認める。集計数だけで実物の無い成果を主張しない。確定改善額と未確定候補は混ぜない。
- 次の冒険：将来の大きな約束ではなく、今確認できる候補をひとつ。未確定候補がなければ無理に創作しない。先の目的地が決まっていなくても歓迎する。
- UIは新しいカードを足さず、既存の**戦果報告後のムダギリくんの1セリフのみ**差し替え。リザルト冒頭JOBカードや未確定候補の内訳を見えづらくしない。

| 監査観点 | 合格条件 |
|---|---|
| 行動経済学 | やることを増やすより、優先度の高いひとつの確認で着手しやすくする |
| 心理学 | 自己効力感と自律性を損なわない。恥・責め・「浪費家」というレッテルを避ける |
| マーケティング | 相談が「できていない指摘を受ける場」ではなく、守るものと次の一手を整理する場として自然に伝わる |
| バズ理論 | 支出を責めるより「守る支出も戦果」というポジティブな物語を保持。個人の支出額は共有に含めない |

回帰：全12カテゴリのうち`protect/ok`が含まれるsynthetic VMでポジティブな声が出ること、集計数のみで実レコードのないVMでは実績を捏造しないこと、未確定ゼロケースでも一歩を提示することをSSR QAで監査する。QA PASSは人間の感想やCVの証明ではない。
