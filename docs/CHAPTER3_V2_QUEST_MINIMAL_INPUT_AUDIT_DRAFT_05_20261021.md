## 2. 最小入力で意味のあるRPGを維持する台本

### PROLOGUE（新規回答なし）

背景は既存第2章のギルドの門につながる、まだ地図が閉じている門外。ギルドの回想カードは**本人の実JOB/STYLE、A(確認できた改善機会)とC(未確定候補)の違いが分かる形**。Aを「獲得した金貨」と誤認させない。

ムダギリくん（仮）：「家計の戦い、おつかれ！ 今度は、君がその先で何を叶えたいか、一緒に地図にしてみよう。」

主操作は「未来の地図を開く」。主回答にはカウントしない。

### QUEST 1｜願いの旗

**C2目標が検証済みで引継ぎできる場合**：
ムダギリくん：「前のクエストで『{第2章で選んだ目標の正本名称}』を選んでいたね。今回もそこを目指す？」
- メイン：「この旗で進む」
- サブ：「目的地を変える」

**C2で目標が未選択／不明な場合**：
ムダギリくん：「いま一番近づきたい未来、どの景色？」
- 「暮らしにもう少し余裕がほしい」
- 「収入を増やして、できることを広げたい」
- 「自分や大切な人の時間を増やしたい」
- 「新しいことに挑戦したい」
- 「将来のお金の心配を減らしたい」
- 補助：「まだ決めていない」

※6要素のタップ負荷はPilotで要確認。C2から「家族・教育」「住まい」等を引き継げる場合は前回の**固有テーマを保持**し、新しい5つのラベルへ機械的に丸めない。任意で「今は収入も増やしたい」等の変更を許可する。

**演出**：選んだ旗が点灯し、これまで暗かった地図の先に道筋が一つ浮かぶ。次画面に旗・JOBの紋章を引継ぎ。「収入の灯」は稼得能力や将来の金額を表さない。

### QUEST 2｜霧の関門（今回の唯一の新しい必須診断情報の候補）

**シーンの因果関係**：前に進むと霧の関門。目標の旗は見えているが、途中の道が一部隠れている。自分で「先に確かめたい部分」に灯りを当てる。

ムダギリくん：「その未来へ進むなら、**今いちばん確かめたいのはどれ？**」

- \`time\`「進めるための時間をつくれそうか」
- \`funds\`「使えるお金にどのくらい余裕があるか」
- \`options\`「どんな選択肢があるか」
- \`timing\`「いつまでに、何を目指すか」
- \`nothing\`「今のところ大きな迷いはない」
- 補助 \`unsure\`「まだ分からない」

**心理面での修正**：障害があることを前提に「何に困っている？」と決めつけず「まず確かめたいこと」に言い換える。選択肢は否定形より中立寄り。C2ですでに「将来目標未定」を選んだなら\`timing\`だけを正解風に見せない。

**演出**：選んだ霧の領域だけ明るくなる。どれでも「冒険失敗」にはならず、地図に次の調査ポイントが記される。この情報は**シェアカードへ含めない**。

**得られる情報**：「本人がまず確かめたいこと」だけ。本当に時間が不足している・ローンがある等は未確認。金融商品の可否判断には使わない。

### QUEST 3｜必要なときだけ旅支度

**追加の確認が出力を変える可能性がある場合のみ表示**：

1. E1が「収入増」、E2が「どんな選択肢があるか」で、時間・経験・技能が出力文言に必要な場合：
   - 「今の自分から使えそうなものは？」→「時間」「経験」「両方」「まだ分からない」。どれでも**転職/起業向き判定にはしない**。
2. E1または引継ぎ目標が「資産形成/老後/将来安心」、E2が「使えるお金」で、使用時期を優先すべき場合：
   - 「そのお金、使う予定は近そう？」→「1〜3年内」「もっと先」「まだ決めていない」。**ここで金額や損失許容力は確認されない**。短期=運用不適合を自動確定するのではなく、「近い資金を守る条件を確認」へ。
3. それ以外は「選んだ旗と関門が道具になって地図へ刻まれる」5〜10秒程度を上限**目標とする演出**（実際の所要時間は未検証。待機強制はせずスキップ可能にする）。補助の回答は追加しない。

**必須ではないシーンの役割**：回答数を増やさずRPGとしての獲得感を出す。背景画像は後制作。新規のムダギリくんポーズが不要なら既存のGUIDE/EXPLAIN/RESULTを使用。

## 3. 結果への分岐：情報を稼ぐ・育てる・整えるの3固定タイプに変換しない

データの証拠優先順位：
1. C1：本人確認済みJOB/STYLE（自己理解、商品適性・適職には使わない）。
2. C2：12カテゴリの状態、確定改善**機会**A、未確定見直し候補C、守る支出、選択済み目標が**明示的に引継がれた場合のみ**。
3. C3：本人の明示選択（目標/いちばん確かめたいこと/必要時の補助）。
4. **推論できないこと**：預貯金、債務、許容損失、実際の増収可能性、生活防衛資金、資金運用余力。

各リザルトの第一画面：
- 上：正本JOB画像・『未来の地図がひらけた』。
- 一手：**今の段階でまず何から確かめるとよいか、動詞と対象を含める**。
- 根拠（2点）：C1/C2/C3の引用可能な本人事実。ただし強い推奨を支える独立根拠がないなら**断定を弱める**。「2回答ある」ことを「第三者検証済み」と誤認しない。
- 「第2章の戦果とどうつながるか」：A/C/守るカテゴリを**該当するときだけ**説明。「お金を増やした」「貯金できた」と書かない。
- 面談CTA：「次の一手を相談する」＋本人に合わせた補助コピー。テーマは本人が編集可能、対応できるサービス範囲の説明を付ける。
- 面談しない場合にも今日できる一歩。
- 下：道標と地図とJOBの冒険録。シェアはJOB/行き先と一般的な抽象表現だけ。

### 反例・失敗ケース（必ずQA）

- C2目標\`undecided\`なら第3章で「老後」と勝手に補完しない。
- \`goal_selected\`イベントが記録されていても第3章へ本人確認なく引き継がない。
- C2で選択した\`invest\`は希望テーマ。投資資金の存在でもリスク許容度でもない。
- C2でサブスクの\`confirmedA\`があるだけでは、**契約停止済みでも毎月余剰現金が増えたわけでもない**。
- C2 \`cUpper\`が大きくても、資金負担能力や投資額の目安へ換算しない。
- C3「お金について迷いなし」と選んでも、負債・家計管理が完全だと判定しない。
- C1 JOB/STYLEが無いか匿名ID不一致なら、別ユーザーのJOB画像を使わない。
- E3の補助問いが3つ以上連鎖してアンケート化することは禁止。1つまで。
- 所得が高くても時間が欲しい本人には副業を強制せず、所得が低くても転職の適性を自動判断しない。
- E3追加の有無で結果の断定度は適切に変えても、同じデータ条件なら矛盾した助言が出ないこと。
