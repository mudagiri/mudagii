## 数値検証（費目範囲の近い2種類のみ）
式：**旧2025月平均費目額 × 旧所得係数 × 旧年齢係数**（2025モデル予測）。公式同時集計：**2024年の同じ年齢・所得・二人以上・勤労者世帯セルの費目平均**。誤差率は予測額と公表費目額の差で計算。

```
MAPE = mean(abs(predicted_yen - official_yen) / official_yen) × 100
WAPE = sum(abs(predicted_yen - official_yen)) / sum(official_yen) × 100
official burden % = official_2024_expense / official_2024_disposable × 100
illustrative model burden % = model_2025_predicted_expense / official_2024_disposable × 100
```

2024年の公開高所得原表12セル（30/40/50/60/70代、世帯年収1,000～1,249 / 1,250～1,499 / 1,500万円以上のうち各概数標本n>=50）。**同じ世帯条件であっても2024年と2025年の年度は違う**。分母は2024年実測値をモデルの説明のために借りているため、実務の2025年負担率予測を完成させたものではない。

|費目|件数|MAPE|最大誤差|平均符号付き相対誤差|
|---|---:|---:|---:|---:|
|食料|12|4.12%|11.00%|+0.67%|
|光熱・水道|12|8.63%|23.30%|−0.50%|

**例**：40代／二人以上／勤労者／年収1,500万円以上：
公式2024年の食料 ¥132,463 / 月・可処分所得 ¥965,121 / 月（公表率13.73%）。2025旧モデルの食料推計 ¥131,546（同じ2024分母で計算した説明専用の率13.63%）。精度差約0.7%はこの1セルに限る。

## 採否基準
|状態|判定|

| `MODEL_REFERENCE` | 直接公表セルが使えない場合。費目一致の確認、別年度/別層の保留検証、予測誤差・バイアス・小標本・係数上限・分母の年次一致を監査後に初めて候補化。現在 **未承認**。 |
| `AUDIT_ONLY` | サブスク／自己投資、費目の境界差が大きい保険/通信/車/住居/教育など。個別契約・用途・生活背景の説明を優先。 |

### 厳守
- 旧係数×年齢係数の推計を「公式の同年代×同年収平均」と呼ばない。
- 2024年原表が有効なら推計より優先。2024と2025の公式原表を無条件に混ぜない。
- 単身世帯の高所得は旧係数が年収600万円以上で停止、2024交差セルには今回のn>=50を満たすものがない。「1,500万円以上単身平均」の推計を捏造しない。
- MAPEが4.12%であっても、12セルと食費だけでは本番採用の統計的保証にならない。地域、非勤労世帯、家族人数差、特定の2026年ユーザーへの外挿は未検証。
- 光熱水道の最大誤差23.30%はモデル改善対象。現状は **研究のみ**。
- 推計参考率と本人の負担率を比較する場合、支出範囲・分母（年間賞与を含む公式可処分所得と本人の月手取り）が異なる。**差額 ≠ ムダ額 ≠ 改善額**。
- `confirmedA`, `cUpper`, `GAS`, `LINE`, 第3章金額予測、シェア金額に新推計値を加算しない。旧Excelの `TARGET_MASTER` / `reducible_rate` を復活させない。

## 続く工程とGo条件
1. 旧係数の6費目すべてを `CANONICAL_OWNER` と原表細品目に照合。「使う/表示しない」の12カテゴリ対応表を完成。

3. **推計の学習/調整に使ったセルを検証に重用しない**。留保層や別年度の外部観測でMAE/WAPE/MAPE、年齢×所得帯の偏り、最大誤差、過大表現を監査。閾値は費目別の事業上の誤認リスクに応じて事前登録。
4. 許可された費目のみに型レベルの `DIRECT / MODEL / AUDIT` 表示と根拠注記を付ける。第2章V3.2隔離プレビューのUI監査（行動経済学/心理学/マーケティング/バズ理論）とiOS/Android QAが通ってから採用する。
5. 公式/推計のいずれも削減可能額へ加算せず、比較表示やアクション導線への効果を予約完了ベースで検証。

## 2026-10-21 追加ストレステスト：年収500～999万円（旧係数の妥当性を再評価）

2024年同じ第1-29-1表の `age-income-joint-multi-2024-official-v1.ts`（単身を含まない全国二人以上×勤労者×世帯主年齢×額面世帯年収）には公式採録済み59セル。そのうち旧モデルの係数ドメイン `500～999万円` に属する**49セル**で検証。400～499万円の10セルは係数定義域外として除外。

検証の仮定：
- 各50万円帯の中間値を当該年収帯の代理値として利用（例：550～600万円は575万円）。これは公表された階級内の実際の平均所得ではない**推計者仮定**。
- 旧 `INCOME_ANCHORS` の整数年収節点（500/550/599/600/650/700/750/800/900/1000）間を線形補間、旧 `AGE_BANDS` で年代係数を取得。**30歳未満は30代の係数ではなく、専用係数（食費0.8077・光熱0.8500）**を使用。
- 旧 `REFERENCE_BASE` 全国基準 × 所得係数 × 年齢係数。2024元表に照合する費目は食料・光熱水道のみ。2024年公式同条件平均可処分所得を実務用2025モデルの分母として使用しない。

|費目|交差セル数|MAPE|WAPE|平均符号付き相対誤差|最大誤差|
|---|---:|---:|---:|---:|---:|
|食料|49|**12.93%**|12.21%|**+12.02%**|31.82%|
|光熱・水道|49|**8.45%**|7.99%|**+7.55%**|25.92%|

30歳未満・550～600万円（n=50）では、食費の2024公式平均¥55,064に対して旧モデル推計約¥72,584、誤差+31.82%。光熱水道も¥16,190に対して約¥20,386、+25.92%。n=50は公表セル採録最低条件に過ぎず、狭い母集団の安定性の保証ではない。

**判断変更**：1,000万円以上12セルだけでは食費MAPE4.12%だったが、500～999万円の49セルでは12.93%かつ過大推計バイアス+12.02%。光熱水道は高所得12セルでも最大23.30%の誤差。したがって、**旧係数モデルを校正なしに診断結果へ採用する選択肢は見送る**。費目と年収帯によって系統誤差が変わるため、一律の「現実的な補正率」に置き換えることも不可。実測交差セルがある層ではその実測を使う。

新規監査コード：`chapter2-peer-model-middle-income-audit-v1.ts`、`qa-chapter2-peer-model-middle-income-audit-v1.ts`。両方とも**研究専用**、診断結果と一切接続しない。

残す選択肢：
- 公式公表の原表交差率：DIRECTとして従来通り拡張。
- 公式の数値と係数モデル：公式セル未観測の条件に対する**推計方法候補**。事前の精度基準・保留検証・階級内分布・元カテゴリ差・2024/2025年差を改めてクリアした時だけMODELを画面候補化。
- 契約型・用途型：平均より行動アドバイスと利用確認を優先。
